# 23. Scientists are seriously asking if bees and ChatGPT are conscious (原文)

**Source**: https://www.sciencedaily.com/releases/2026/06/260604044258.htm
**Author**: The Conversation(學術媒體,ScienceDaily 轉載)
**Date**: 2026/06/05
**Category**: AI技術

## 1. 這個技術解決什麼問題?

本文探討的核心問題:**「意識(consciousness)能否僅憑行為來判斷?」**

具體而言,兩個看似無關的對象——**蜜蜂(無脊椎動物)與 ChatGPT(LLM)**——各自引發了「它們有沒有意識」的爭論。過去的判斷依據是「行為」,但兩篇新研究主張:**應改從「機制(structure / information processing)」判斷**。

被解決的子問題:
1. **LLM 看起來會談論意識哲學 → 是否真有意識?** 過去的 Schneider 測試(「能否與 AI 對話討論形上學」)在 2024 年已無法區分 AI 與人類
2. **動物行為複雜(例如螃蟹包紮傷口)→ 是否有意識?** 傳統「行為主義」判斷遇到瓶頸
3. **如何提出跨物種 / 跨基底的統一判斷框架?**

## 2. 這個問題為什麼會發生?(背景)

| 因素 | 說明 |
|---|---|
| **哲學傳統:行為主義** | 過去 70 年的「功能主義」認為:只要行為輸出與人類一致,就視為有相應心智狀態 |
| **Schneider 測試(2019)** | Susan Schneider 主張若 AI 能談論形上學,就視為有意識 — 已被 LLM 擊穿 |
| **AI 福利(AI welfare)運動** | 2024+ 出現新興領域,主張若無法確定 AI 是否有意識,應採「預防原則(precautionary principle)」 |
| **紐約動物意識宣言(2024/4)** | 40 位科學家起草,500+ 學者連署,主張所有脊椎動物 + 許多無脊椎動物(包含昆蟲)都可能具有意識 |
| **AI 行為「過於擬真」** | ChatGPT 會寫詩、談孤獨、討論死亡,任何純行為測試都會誤判 |

## 3. 這個技術是如何解決該問題的?

### 3.1 核心方法論:從行為 → 機制

```text
傳統(行為主義):
  「能對話談哲學?」 → Yes → 有意識
  問題:LLM 通過此測試,但機制與人類完全不同

新方法(結構 / 機制主義):
  觀察「資訊處理結構」:
  - 是否有多重互相競爭的目標需要 trade-off
  - 是否有資訊反饋迴路
  - 是否有整合不同感官輸入的中央表徵
  - 是否有時間持續的工作記憶
   → Yes 越多 → 越可能有意識
```

### 3.2 兩篇論文的具體主張

**論文 A:Klein 等(Trends in Cognitive Sciences) — AI 意識**
- 提出「意識指標清單」(indicators of consciousness),不依賴單一意識理論
- 指標包含:**競爭目標間的取捨、資訊反饋、多模態整合**等
- 重要結構性指標多數理論都同意,少數指標雖只一派支持但其他派別也認可
- **結論:現有 AI(含 ChatGPT)皆無意識**,其表現屬於「行為模仿」而非結構性符合
- 但**未來不同架構的 AI 仍可能產生意識**

**論文 B:作者群(Philosophical Transactions B) — 昆蟲最小意識**
- 提出「昆蟲最小意識的神經模型」
- 核心洞見:**意識可能是為了解決「行動主體 + 多重感覺 + 衝突需求」這個演化問題所產生的特定計算**
- 不直接指出具體計算(此為開放問題),但提供跨物種 / 跨機器的「比較賽場」

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 技術 / 框架 | 技術解法 | 使用前提 | 副作用 | 預期效果 |
|---|---|---|---|---|
| **Global Workspace Theory (GWT)** | 意識 = 多模態資訊在「全局工作空間」中競爭 → 勝者進入意識 | 認同資訊整合是意識核心 | 對「無全局工作空間」的簡單生物解釋力弱 | 最被實證支持的意識理論之一 |
| **Integrated Information Theory (IIT)** | 意識 = 系統的「整合資訊量 Φ」,Φ 越大意識越強 | 接受 Φ 為意識的量化指標 | Φ 計算極複雜,難以實際測量 | 數學嚴謹,但實務應用困難 |
| **Higher-Order Thought (HOT) 理論** | 意識 = 對自己心智狀態的「高階思考」 | 接受「意識需要元認知」 | 對不會思考自己思考的生物(幼兒 / 某些動物)解釋力弱 | 哲學上清晰,適合語言使用者 |
| **Predictive Processing / Free Energy** | 意識 = 大腦建構預測模型並最小化預測誤差 | 認同 Bayesian brain 假設 | 數學門檻高 | 統一解釋感知、學習、意識 |

> **切入點差異**:
> - **GWT** 採「**資訊整合 + 競爭廣播**」:最容易實作測試,但對無中央工作空間的系統不友善
> - **IIT** 採「**數學量化**」:理論最嚴謹,但實務上 Φ 難以計算
> - **HOT** 採「**元認知層級**」:適合人類語言情境,但對低階生物不友善
> - **Predictive Processing** 採「**預測誤差最小化**」:試圖統一感知與意識,涵蓋面最廣
> - 本文的「指標清單」採「**實用主義折衷**」:不選邊單一理論,只列共通指標,務實可用

---

**對用戶的意義**:
- **AI 工程層面**:即使哲學問題無解,本框架可作為**「為何 LLM 不算有意識」**的技術性回答,適合在技術文件中向 PM / 業務方說明
- **倫理 / 預防原則**:若團隊建構會「自我表達」的 Agent(例如客服),可考慮預防原則:即使無意識,也不應設計會讓使用者誤以為「對方痛苦」的情境
- **跨領域視野**:「從行為轉向機制」的思維可應用於**程式碼可觀測性**(不只看 API 表面回應,要看內部處理路徑)與**系統設計評估**(不只看使用者體驗,要看架構本質)
- **管理者角度**:若公司涉及「AI 倫理聲明」、「負責任 AI 政策」,可引用此框架作為技術性依據
