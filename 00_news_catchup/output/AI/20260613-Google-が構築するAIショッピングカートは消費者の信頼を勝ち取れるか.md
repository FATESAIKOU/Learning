# 07. Google が構築するAIショッピングカートは消費者の信頼を勝ち取れるか

**Source**: https://digiday.jp/modern-retail/google-attracts-retailers-like-walmart-target-to-universal-cart-getting-shoppers-will-be-the-harder-part/
**Author**: DIGIDAY 日本版
**Date**: 2026-06-13
**Category**: AI技術

## 1. この技術/政策は何を解決するのか?

Google Universal Cart（ユニバーサル・カート）解決的核心問題是：**消費者在跨多個零售商、多個 Google 服務的購物旅程中，缺乏一個統一的購物車來管理商品比較、價格追蹤、相容性檢查與購買決策**。

當前消費者的購物旅程碎片化現狀：

```
現狀：碎片化的購物旅程

  發現商品          比較/研究            決策              購買
  ┌────────┐      ┌────────┐        ┌────────┐       ┌────────┐
  │Google  │      │各零售商│        │筆記/   │       │各零售商│
  │Search  │ ──→  │網站    │  ──→   │記憶    │ ──→   │結帳頁  │
  │YouTube │      │評測網站│        │        │       │        │
  │Gemini  │      │比價網站│        │        │       │        │
  └────────┘      └────────┘        └────────┘       └────────┘
       ↓               ↓                ↓                ↓
  無統一儲存      需反覆切換        無價格追蹤        需重複輸入
  感興趣商品      不同網站          無庫存通知        付款資訊

Universal Cart 的目標狀態：

  發現商品          加入 Cart           Cart 持續管理        購買
  ┌────────┐      ┌─────────────┐    ┌──────────────┐   ┌────────┐
  │Google  │      │ Universal   │    │ 價格追蹤      │   │Google  │
  │Search  │ ──→  │ Cart        │ ──→│ 降價通知      │ ──→│Pay 或  │
  │YouTube │      │ (跨服務/     │    │ 再入荷通知    │   │零售商  │
  │Gemini  │      │  跨零售商)   │    │ 互換性檢查    │   │サイト  │
  │Gmail   │      │             │    │ 替代品提案    │   │        │
  └────────┘      └─────────────┘    └──────────────┘   └────────┘
```

## 2. この問題が発生する背景は?

### 2.1 Google 在電商領域的戰略位置

Google 在電商生態系中的獨特位置：

```
Google 的電商觸及點:

  Google Search ──── 每日數十億次商品相關搜尋
  Google Shopping ── 商品列表與比價（Shopping Graph 包含 450 億+ 商品）
  YouTube ────────── 產品評測、開箱、教學影片（第二大搜尋引擎）
  Gemini ─────────── AI 助手可進行對話式購物建議
  Gmail ──────────── 訂單確認、運送通知、促銷郵件
  Google Pay ─────── 已儲存數億用戶的付款資訊
  Chrome ─────────── 自動填入地址/付款資訊
```

Google 擁有購物旅程中幾乎所有「發現與研究」階段的觸及點，但缺乏「決策管理」與「購買」階段的統一工具。Universal Cart 是填補這一缺口的戰略產品。

### 2.2 零售商與平台的張力

零售商對 Universal Cart 的矛盾態度：

| 立場 | 觀點 |
|------|------|
| **支持理由** | Google 的流量規模無可匹敵；Cart 可降低購物車放棄率；AI 推薦可能增加客單價 |
| **反對理由** | Cart 可能減少零售商自身網站的直接流量；消費者關係從「品牌-消費者」變為「Google-消費者」；Google 掌握更多消費者數據 |
| **觀望理由** | Google 承諾不收取交易手續費（「仲介役であってマーケットプレイスではない」）；初期合作零售商（Nike, Sephora, Target, Walmart）的品牌力足以平衡風險 |

### 2.3 消費者購物行為的結構性變化

2024-2026 年消費者購物行為的關鍵趨勢：

| 趨勢 | 數據/表現 | 對 Universal Cart 的影響 |
|------|----------|--------------------------|
| **搜尋起點多元化** | 40%+ 商品搜尋從 Amazon 而非 Google 開始 | Google 需強化購物閉環以防守搜尋份額 |
| **AI 助手購物** | Gemini/ChatGPT 的商品推薦使用率快速上升 | Cart 是 AI 推薦到購買的「最後一哩」 |
| **跨零售商比價** | 消費者在購買前平均訪問 3-5 個零售商網站 | Cart 可將比價行為統一在 Google 生態系內 |
| **社交商務** | TikTok Shop、Instagram Shopping 的崛起 | Google 需以 AI 差異化（相容性檢查、價格預測）對抗社交商務 |

## 3. この技術/政策はどのようにその問題を解決するのか?

### 3.1 消費者價值主張

| 功能 | 解決的具體問題 | 技術實現 |
|------|---------------|----------|
| **跨服務購物車** | 在 Search 看到的商品、YouTube 評測推薦的商品、Gemini 對話中建議的商品，無需分別管理 | 統一的 Google 帳戶層購物車狀態 |
| **價格追蹤** | 加入購物車後不知何時購買最划算 | Shopping Graph 的即時價格數據 + 歷史趨勢分析 |
| **再入荷通知** | 感興趣的商品缺貨後需反覆手動檢查 | 零售商庫存 API 整合 + 主動推送 |
| **互換性檢查** | 購買不相容的配件/零件（如錯誤的手機殼型號、不匹配的充電器規格） | 商品規格知識圖譜 + 規則引擎 |
| **替代品提案** | 缺貨或不相容時不知有何替代選擇 | AI 推薦引擎 + Shopping Graph |
| **統一結帳** | 跨多個零售商結帳需重複輸入付款/地址資訊 | Google Pay 整合 + Chrome 自動填入 |

### 3.2 Google 的商業模式設計

Google 對 Universal Cart 的商業模式定位：

```
Google 的明確表態:
  「仲介役であってマーケットプレイスではない」
  （是中介角色，不是市集）

具體含義:
  ✗ 不從交易中收取手續費
  ✗ 不持有庫存
  ✗ 不處理物流
  ✓ 提供購物決策輔助工具
  ✓ 將消費者導向零售商完成購買
  ✓ 透過廣告/購物廣告獲利（既有的商業模式）
```

這一設計的戰略意圖：

- **避免與 Amazon 直接競爭**：Amazon 是市集（marketplace），Google 定位為中介（intermediary）
- **維持零售商關係**：不收手續費意味著不與零售商爭利
- **強化搜尋廣告價值**：Cart 使 Google 搜尋廣告的轉化路徑更短、更可追蹤
- **數據網絡效應**：Cart 中的商品互動數據可回饋至搜尋/推薦演算法

### 3.3 信任問題：普及的關鍵障礙

文章明確指出「普及のカギは消費者の信頼にある」。信任問題的三個層次：

```
消費者信任的三層障礙:

第一層：數據隱私信任
  「Google 是否會利用 Cart 中的購物數據進行過度個人化或廣告追蹤？」
  → Google 的廣告商業模式與消費者隱私之間的固有張力

第二層：推薦中立性信任
  「Cart 推薦的商品是真正最適合我的，還是廣告出價最高的？」
  → 搜尋廣告與有機推薦的邊界模糊化

第三層：執行可靠性信任
  「價格追蹤準確嗎？互換性檢查會出錯嗎？再入荷通知及時嗎？」
  → AI 系統的實際執行品質需時間驗證
```

### 3.4 競爭優勢分析

Wayvia（eコマース分析企業）CEO 的警告與 Google 的優勢：

| 維度 | 風險（Wayvia 觀點） | Google 的優勢 |
|------|-------------------|---------------|
| **零售商流量** | Cart 可能減少零售商自身網站流量 | Google 承諾將消費者導向零售商結帳 |
| **消費者關係** | 品牌-消費者關係被 Google 中介化 | 零售商可透過 Cart 獲得新的消費者觸及點 |
| **信任基礎** | 新產品需要時間建立信任 | Google 是既有科技巨頭，非 OpenAI 式新興勢力，信任基礎較強 |
| **數據控制** | Google 掌握更多消費者行為數據 | Google 已掌握這些數據（Search/YouTube/Gmail），Cart 不改變數據所有權 |

## 4. 類似の問題を解決する他の技術/フレームワーク/考え方は存在するか?

### 4.1 統一購物體驗的競爭格局

| 平台 | 產品 | 策略 | 與 Universal Cart 的差異 |
|------|------|------|--------------------------|
| **Amazon** | Amazon Cart + Wishlist | 封閉生態系內的統一購物車 | 僅限 Amazon 及第三方賣家，不跨外部零售商 |
| **Shopify** | Shop App + Shop Pay | 跨 Shopify 商家的統一購物體驗 | 僅限 Shopify 生態系內商家 |
| **Apple** | Apple Pay + Wallet | 統一結帳層，非購物車層 | 聚焦結帳便利性，不提供商品發現/比較/管理 |
| **PayPal** | PayPal Shopping | 跨零售商結帳 + 優惠發現 | 聚焦交易層，不提供購物車管理 |
| **Google** | Universal Cart | 跨服務、跨零售商的 AI 購物車 | 唯一在「發現→管理→結帳」全鏈條提供統一體驗 |

### 4.2 購物車作為平台的戰略邏輯

Universal Cart 代表了「購物車從工具升級為平台」的戰略轉變：

```
傳統購物車（工具邏輯）:
  商品暫存 → 結帳 → 清空
  功能：交易輔助
  價值：便利性

AI 購物車（平台邏輯）:
  商品發現 → 持續管理（追蹤/比較/檢查） → 最佳時機結帳
  功能：購物決策平台
  價值：省錢 + 省時 + 避免錯誤購買
```

### 4.3 對日本市場的潛在影響

Universal Cart 預計 2026 年夏季在美國先行推出，日本市場的展開時程未定。但基於日本電商市場的特徵，可預測以下影響：

| 日本市場特徵 | 對 Universal Cart 的影響 |
|-------------|-------------------------|
| **楽天市場の支配力** | 楽天是封閉生態系（楽天 ID + 楽天 Pay + 楽天 Card），Google Cart 難以整合 |
| **Amazon Japan の強さ** | Amazon 是 Google 在商品搜尋起點上的最大競爭者 |
| **ポイント文化** | 日本消費者對點數經濟的高度敏感，Cart 若無法整合各零售商的點數系統將受限 |
| **QR 碼結帳普及** | PayPay 等 QR 碼結帳的普及使 Google Pay 的優勢不如在美國明顯 |
| **高齢消費者の數位落差** | 統一數位購物車對高齡消費者的吸引力有限 |

### 4.4 成敗關鍵的總結

Universal Cart 的成功取決於三個條件的同時滿足：

```
必要條件 1: 消費者信任
  → 數據使用透明、推薦中立、執行可靠
  → 信任建立需要時間，無法透過功能堆疊加速

必要條件 2: 零售商採納
  → 初期合作零售商（Nike, Sephora, Target, Walmart, Wayfair, Shopify）的持續參與
  → 中小零售商的跟進意願（庫存 API 整合的技術成本）

必要條件 3: 與 Amazon 的差異化
  → 若 Cart 僅是「跨零售商的 Amazon Cart 複製品」，消費者無遷移動機
  → AI 功能（互換性檢查、價格預測、替代品推薦）是核心差異化武器
```

Google 的優勢在於其既有生態系的完整性（Search + YouTube + Gemini + Gmail + Pay + Chrome），但劣勢在於其廣告商業模式與消費者信任之間的結構性張力。Universal Cart 的成敗將是「生態系完整性」與「信任赤字」之間的拔河。
