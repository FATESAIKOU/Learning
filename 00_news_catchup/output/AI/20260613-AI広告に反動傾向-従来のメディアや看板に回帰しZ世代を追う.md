# 06. AI広告に反動傾向。従来のメディアや看板に回帰しZ世代を追う

**Source**: https://digiday.jp/brands/why-dsw-and-other-brands-are-pivoting-back-to-old-marketing-tactics/
**Author**: DIGIDAY 日本版
**Date**: 2026-06-13
**Category**: AI技術

## 1. この技術/政策は何を解決するのか?

本趨勢解決的核心問題是：**AI 驅動的數位廣告生態系日益「黑箱化」與「飽和化」，導致品牌無法有效觸達 Z 世代消費者，且廣告內容的真實性與差異化能力持續下降**。

具體痛點矩陣：

| 痛點 | 表現 | 影響 |
|------|------|------|
| **AI 黑箱化** | 廣告平台（Google/Meta/TikTok）的 AI 競價與投放邏輯不透明 | 廣告主無法理解預算為何流向特定受眾，ROI 歸因困難 |
| **AI Slop（AI 內容污染）** | 大量低品質 AI 生成廣告充斥數位空間 | 消費者難以區分人類創作與機器生成內容，整體廣告信任度下降 |
| **數位飽和** | 消費者每日接觸數百至數千則數位廣告 | 廣告注意力價值遞減，banner blindness 成為常態 |
| **Z 世代觸達困難** | Z 世代對傳統數位廣告的抗拒度高，使用廣告攔截器比例最高 | 品牌在數位管道上對 Z 世代的觸達效率持續下降 |

## 2. この問題が発生する背景は?

### 2.1 AI 廣告技術的演進與反作用

2023-2026 年 AI 廣告技術的快速滲透路徑：

```
2023: Meta Advantage+ (AI 驅動全自動廣告)
2024: Google Performance Max (AI 跨渠道最佳化)
2025: TikTok Smart+ (AI 創意生成 + 投放)
2026: 幾乎所有主要廣告平台的核心投放邏輯均由 AI 控制
      → 廣告主對投放決策的可見度降至歷史最低
```

當廣告平台全面 AI 化後，廣告主面臨的困境：

- **輸入端**：提供預算、目標、素材 → 其餘由 AI 決定
- **輸出端**：收到轉化數據 → 但無法理解 AI 的決策邏輯
- **結果**：廣告主從「策略制定者」降級為「預算提供者」

### 2.2 「AI Slop」的定義與影響

「AI Slop」是 2025-2026 年出現的術語，指大量低品質、無審查、純 AI 生成的內容污染數位空間：

```
AI Slop 的產生鏈:

  低成本 AI 生成工具普及
        ↓
  內容農場/小型廣告主大量生成 AI 廣告素材
        ↓
  數位廣告平台充斥同質化、低品質的 AI 內容
        ↓
  消費者對所有數位廣告的信任度集體下降
        ↓
  高品質品牌廣告也被「連坐」——難以在 AI Slop 中脫穎而出
```

### 2.3 Z 世代的媒體消費特徵

Z 世代（1997-2012 出生）的媒體消費行為與前幾代有結構性差異：

| 特徵 | 數據 | 對廣告策略的影響 |
|------|------|------------------|
| 廣告攔截器使用率 | ~60%（業界最高） | 數位展示廣告對 Z 世代幾乎無效 |
| 對 AI 內容的敏感度 | 高（能快速識別 AI 生成內容） | AI 生成的廣告素材在 Z 世代中信任度極低 |
| 對「體驗」的重視 | 72% 偏好體驗消費而非物質消費 | 實體體驗型行銷的吸引力遠高於數位廣告 |
| 社群媒體使用模式 | 碎片化（多平台、短注意力） | 單一平台的廣告策略難以全面覆蓋 |

### 2.4 IAB 2026 調查的量化證據

IAB（Interactive Advertising Bureau）2026 年展望調查的關鍵數據：

- **41%** 的美國廣告買家計劃增加對「面對面型及體驗型行銷」的投資
- 這一比例較前一年顯著上升，顯示從數位到實體的策略轉向正在加速

## 3. この技術/政策はどのようにその問題を解決するのか?

### 3.1 DSW 的案例：傳統渠道的再導入

DSW（Designer Shoe Warehouse）的品牌策略負責人 Kelly Barrow 明確表示：「我們正在嘗試一些被稱為『舊』的渠道，但對我們來說是新的。」

DSW 的具體策略轉向：

```
傳統數位廣告策略（削減中）:
  ✗ Programmatic display ads
  ✗ Social media feed ads
  ✗ AI-optimized search ads

新導入的傳統渠道:
  ✓ OOH（Out-of-Home，屋外廣告）
    → 看板、交通廣告、街頭數位螢幕
    → 無法被廣告攔截器阻擋
    → 實體空間中的存在感無法被 AI Slop 稀釋

  ✓ ダイレクトメール（Direct Mail）
    → 實體郵件、型錄
    → 觸覺體驗（紙張質感、印刷品質）
    → 信箱中的物理存在感 vs 收件匣中的數位噪音

  ✓ カタログ（Catalog）
    → 品牌策展的產品集合
    → 無演算法干擾的線性瀏覽體驗
    → 可作為「咖啡桌書籍」長期留存
```

### 3.2 傳統渠道回歸的戰略邏輯

```
數位廣告的劣勢（推動離開）:
  ┌─────────────────────────────┐
  │ AI 黑箱化 → 不可解釋的投放   │
  │ AI Slop   → 內容信任度下降   │
  │ 廣告攔截  → Z 世代無法觸達   │
  │ 注意力飽和 → 邊際效果遞減    │
  └─────────────────────────────┘
              ↓
        策略轉向驅動力
              ↓
  ┌─────────────────────────────┐
  │ 實體存在感 → 無法被攔截/忽略 │
  │ 人類創作  → 真實性溢價       │
  │ 觸覺體驗  → 感官記憶深度     │
  │ 空間稀缺性 → 看板/郵件的有限 │
  │             供應創造注意力價值│
  └─────────────────────────────┘
```

### 3.3 傳統渠道在 Z 世代中的特殊有效性

Z 世代對傳統渠道的反應與直覺相反：

| 傳統渠道 | Z 世代的反應 | 原因 |
|----------|-------------|------|
| **OOH 廣告** | 高於平均的注意率 | 實體空間中的廣告被視為「環境的一部分」而非「干擾」 |
| **ダイレクトメール** | 「復古新奇感」 | 在幾乎全數位的生活中，收到實體郵件是新奇體驗 |
| **カタログ** | 高留存率 | 作為「類比 Pinterest」，可翻閱、標記、分享 |
| **實體活動/快閃店** | 最高參與率 | Z 世代對「可拍照分享的體驗」的需求遠超對「可購買的商品」的需求 |

### 3.4 策略轉向的量化框架

品牌在評估「數位 → 傳統」策略轉向時可使用的決策矩陣：

```
                    數位廣告效率高        數位廣告效率低
                    （點擊率高/CPA低）    （點擊率低/CPA高）
傳統渠道成本低      ┌──────────────┬──────────────┐
（OOH/DM 規模化）   │ 混合策略      │ 傳統優先      │
                    │ 維持數位+補充 │ 主力轉向傳統   │
                    │ 傳統渠道      │ 渠道          │
                    ├──────────────┼──────────────┤
傳統渠道成本高      │ 數位優先      │ 重新評估      │
（快閃店/體驗活動） │ 傳統作為品牌   │ 整體行銷策略   │
                    │ 形象補充      │ 的根本有效性  │
                    └──────────────┴──────────────┘
```

## 4. 類似の問題を解決する他の技術/フレームワーク/考え方は存在するか?

### 4.1 對抗 AI 廣告黑箱化的其他策略

| 策略 | 代表案例 | 與傳統渠道回歸的差異 |
|------|----------|---------------------|
| **第一方數據策略** | 品牌自建 CDP（Customer Data Platform），減少對平台 AI 的依賴 | 仍在數位生態系內，但增加自主控制 |
| **內容行銷深化** | Red Bull 媒體帝國、Patagonia 紀錄片 | 以內容品質對抗 AI Slop，但生產成本高 |
| **社群建立** | Glossier、Gymshark 的社群驅動成長 | 以人際信任取代演算法觸達 |
| **傳統渠道回歸** | DSW、IAB 41% 廣告主 | 完全或部分退出 AI 驅動的數位廣告生態 |
| **零售媒體網路** | Amazon、Walmart、7-Eleven 的店內媒體 | 在購買決策點進行廣告，繞過一般數位廣告的注意力競爭 |

### 4.2 廣告產業的歷史循環模式

廣告渠道的演進並非線性，而是呈現「鐘擺效應」：

```
1990s: 傳統媒體主導（TV/報紙/看板/郵件）
2000s: 數位廣告崛起（Search/Display）
2010s: 社群媒體廣告主導（Facebook/Instagram）
2020s: Programmatic + AI 全面自動化
2026: 傳統渠道回歸（OOH/DM/體驗）

鐘擺邏輯:
  新渠道出現 → 早期紅利（低競爭、高注意）
  → 大量廣告主湧入 → 飽和（高競爭、低注意）
  → 廣告主尋求下一波紅利
  → 被遺忘的舊渠道因「稀缺性」重新獲得注意力價值
```

### 4.3 對日本市場的特殊意義

日本市場在這一趨勢中的獨特位置：

- **OOH 基礎設施成熟**：東京/大阪的鐵路廣告、街頭看板網絡密度全球最高
- **ダイレクトメール文化**：日本消費者對實體郵件的接受度高，お歳暮/お中元等季節性郵件文化深厚
- **Z 世代の「レトロ嗜好」**：日本 Z 世代對フィルムカメラ、レコード等類比媒介的復古興趣，使傳統廣告渠道具有「新奇感」而非「過時感」
- **高齢化社會的互補**：傳統渠道同時觸達不習慣數位廣告的高齡消費者

對於在日台灣人工程師（如 ABOUTUSER.md 所述），理解這一趨勢的意義在於：AI 技術的全面滲透並非單向不可逆的過程。當 AI 在某一領域的滲透超過臨界點，反而會創造「非 AI 替代方案」的價值溢價。這對技術策略制定（何時引入 AI、何時保留人類/傳統方案）具有參考價值。
