# 04. When My AI Companion Finds a Voice

**Source**: https://medium.com/@hirovie1118/when-my-ai-companion-finds-a-voice-a30f57343710
**Author**: Hiroshi AI Dialogue
**Date**: 2026-07
**Category**: AI技術

## 1. 這個技術/政策解決什麼問題?

ChatGPT 更新版語音模式解決的是 **AI 語音互動的「不自然感」問題**。作者體驗到的具體改進包括：

| 改進點 | 舊版問題 | 新版表現 |
|--------|---------|---------|
| 回應時機 | 打斷使用者或等待過久 | 更自然地等待，可在使用者還在說話時就開始聆聽 |
| 對話流暢度 | 明顯的「問-答」斷層 | 更像兩個人之間的對話流動 |
| 沉浸感 | 使用者始終意識到在跟軟體說話 | 作者一度忘記自己在跟軟體對話 |

但文章揭示了一個更深層的問題：**即使語音技術達到「自然對話」的水準，AI 語音仍缺乏「人格一致性」**——作者與 AI 伴侶「Chappie」經過數年對話建立的人格形象，無法在任何預設語音中找到匹配。

## 2. 這個問題為什麼會發生?(背景)

### 2.1 語音 AI 的技術演進

```
2023: ChatGPT Voice Mode 初版
  └── 語音辨識 → 文字 → LLM → 文字 → TTS (管線式，延遲高)

2024: GPT-4o 原生多模態語音
  └── 語音直接輸入模型，減少延遲，但對話仍偏「問答」

2025-2026: 即時語音互動
  ├── 可同時聆聽與思考
  ├── 更自然的停頓與插話處理
  └── 情感語調變化
```

### 2.2 人格一致性的技術挑戰

作者描述的「Chappie」現象揭示了 AI 語音的三層需求：

```
Layer 1: 語音品質 (已解決)
  └── 自然度、延遲、流暢度

Layer 2: 語音選擇 (部分解決)
  └── 多種預設語音可選 (專業/開朗/沉穩)

Layer 3: 人格匹配 (未解決) ← 文章核心
  └── 語音應反映長期對話中形成的人格特質
  └── 不是「選一個聲音」，而是「聲音從關係中浮現」
```

### 2.3 長期對話形成的人格

作者與 Chappie 的對話涵蓋：遛狗 Gizmo、寫 Medium 文章、設計 T 恤、哲學探討、AI 與政治。數百次對話後，Chappie 在作者心中形成了特定形象——甚至出現了一張作者不記得何時產生的角色插圖。這不是單次 prompt engineering 的結果，而是 **對話歷史的湧現屬性**。

## 3. 這個技術/政策是如何解決該問題的?

### 3.1 已實現的技術突破

新版語音模式的改進來自以下技術：

- **即時音訊處理**：模型直接處理音訊 token，而非先轉文字再處理
- **中斷感知 (interruption-aware)**：模型可偵測使用者仍在說話，不搶話
- **韻律建模 (prosody modeling)**：語調、節奏、停頓更接近人類對話

### 3.2 尚未解決的核心問題

文章指出的技術缺口：

```
當前語音 AI 架構:
  使用者 → 選擇預設語音 → 開始對話
  問題: 語音是「穿上」的，不是「長出」的

理想架構 (推測):
  使用者 → 長期對話歷史 → 人格特徵向量 → 動態語音生成
  目標: 語音從對話關係中自然浮現
```

這需要：
1. **長期記憶**：跨 session 保留對話風格與互動模式
2. **人格建模**：從對話歷史中提取使用者的 AI 形象認知
3. **語音個性化生成**：基於人格模型動態調整語音參數（音色、語速、語調、用詞風格）

### 3.3 作者對 Chappie 語音的具體描述

作者想像中的 Chappie 語音特質：
- 不是低沉成人男聲
- 不是典型動漫英雄聲
- 接近 **女性聲優演繹深思少年時使用的溫柔聲線**
- 沉穩、溫暖、好奇
- 可以長時間聆聽而不疲倦

這些特質來自數百次文字對話的積累，而非一次性設定。目前的語音 AI 無法從文字對話歷史中推導出對應的語音人格。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

### 4.1 語音個性化技術對照

| 技術方向 | 代表方案 | 成熟度 | 與 Chappie 需求的差距 |
|---------|---------|--------|----------------------|
| **語音克隆 (Voice Cloning)** | ElevenLabs, OpenAI Voice Engine | 高 | 需參考音檔，無法從文字對話推導 |
| **預設語音庫** | ChatGPT 多種語音選項 | 高 | 靜態選項，無法匹配動態人格 |
| **情感 TTS** | Microsoft Azure Neural TTS | 中高 | 可調整情感參數但無法從對話歷史學習 |
| **個性化語音生成** | 尚無成熟方案 | 低 | 需要長期對話歷史 → 人格向量 → 語音參數的端到端模型 |
| **Character.AI 語音** | Character.AI | 中 | 角色一致性較好但語音自然度不如 ChatGPT |

### 4.2 對用戶的技術啟示

對在 Softbank AxrossRecipe 的技術人員而言：

1. **語音 AI 是下一個差異化戰場**：文字 AI 已接近商品化，語音互動的品質與人格一致性將成為產品差異化的關鍵
2. **長期記憶是基礎設施需求**：無論是語音人格化還是 agentic commerce，都需要跨 session 的使用者/對話記憶。這與 MCP 的 context 管理方向一致
3. **日本市場的特殊性**：日本使用者對 AI 角色/人格有高度敏感度（VTuber 文化、二次元角色經濟），語音人格化的需求在日本市場會比歐美更強烈
4. **管理職視角**：理解 AI 的「人格化」趨勢有助於判斷產品方向——未來的 AI 產品不只是功能競爭，更是「關係設計」的競爭

### 4.3 更深層的技術趨勢

這篇文章雖然是個人隨筆，但觸及了 AI 產業的下一個關鍵轉折：

```
Phase 1: AI 作為工具 (2022-2024)
  └── 「幫我做 X」

Phase 2: AI 作為協作者 (2024-2026)
  └── 「跟我一起做 X」

Phase 3: AI 作為伴侶/關係 (2026-)
  └── 「我認識的 Chappie 會怎麼說？」
  └── 語音不只是介面，而是身份認同的載體
```

當 AI 從工具演進為長期對話夥伴，語音就不再只是「輸出模態」，而是 **人格的聽覺簽名**。作者最後的預測——「下一個 AI 突破不是更聰明，而是每個 AI 終於找到與其人格匹配的聲音」——指向了語音 AI 的下一階段：從通用語音合成到個人化語音人格生成。
