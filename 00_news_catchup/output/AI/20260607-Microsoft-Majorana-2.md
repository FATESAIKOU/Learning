# 18. Microsoft Majorana 2: The 1,000x AI-Built Quantum Chip (原文)

## 1. 這個技術解決什麼問題?

Microsoft 發布 **Majorana 2 量子晶片**,解決的問題是:**量子位元(qubit)的相干時間過短,導致量子計算無法執行有實用價值的運算**。

具體痛點:
- 既有量子系統的 qubit lifetime 以**微秒**計(μs = 10⁻⁶ 秒),任何稍長的演算法都會在運算完成前衰減
- 為了解決不穩定,現行方案需要**數百萬個實體 qubit 才能組成少量可靠的「邏輯 qubit」**,成本與工程難度過高
- 量子運算的硬體研發高度依賴試誤,**人工探索新材料的週期過長**

## 2. 這個問題為什麼會發生?(背景)

### 2.1 物理背景

| 因素 | 說明 |
|---|---|
| 量子狀態對環境極度敏感 | 熱、振動、電磁干擾都會使 qubit 退相干(decoherence),運算崩潰 |
| 標準做法:錯誤更正 | 透過多個實體 qubit 投票表決一個邏輯 qubit,但需要極大 overhead |
| Topological qubit(拓樸量子位元) | 利用物質的拓樸性質(本例使用 Majorana 費米子)把資訊編碼在**較難被局部擾動破壞**的全局狀態中 |
| Majorana 費米子爭議 | 2018-2019 微軟發布的 Majorana 1 相關論文曾因實驗可重複性問題遭撤回,此領域外部驗證特別謹慎 |

### 2.2 工程背景

- 新材料堆疊(new materials stack)涉及數百種候選元素 + 製程參數組合,**人工搜尋效率低落**
- Microsoft 採用 **Discovery(代理型 AI 平台)** 加速材料探索與製程優化,結果找到使 qubit 穩定性提升 1000× 的新材料

## 3. 這個技術是如何解決該問題的?

### 3.1 關鍵數字對比

```text
                       Standard Qubit          Microsoft Majorana 2
Qubit lifetime         microsecond (10⁻⁶ s)    20 秒(平均),最長 60 秒
Gate operation speed   ~                       1 microsecond (1 μs)
Qubit physical size    larger                  1/100 mm
Reliability            基準                     1000× (vs 上一代)
```

> Microsoft 類比:相當於「手機電池從只能用 1 天 → 撐 3 年」。

### 3.2 拓樸量子位元的核心機制

```text
┌─────────────────────────────┐
│  Standard Qubit             │
│  ─────────────────────      │
│  資訊儲存在「局部狀態」      │
│  容易被環境擾動破壞          │
│  → 需要大量錯誤更正          │
│  → 數百萬實體 qubit / 1 邏輯│
└─────────────────────────────┘

┌─────────────────────────────┐
│  Topological Qubit          │
│  ─────────────────────      │
│  資訊編碼在「拓樸不變量」    │
│  局部擾動無法改變全域狀態    │
│  → 內建抗干擾              │
│  → 1 個實體 qubit ≈ 1 邏輯  │
│  → 大幅降低硬體規模需求      │
└─────────────────────────────┘
```

### 3.3 AI 輔助開發流程(Microsoft Discovery)

```text
人類工程師 ──→ 標註問題邊界(例如「qubit 在第 47 步製程出現缺陷」)
                          ↓
       Discovery AI Agent Team(多個專門 agent)
                          ↓
       ┌────────┬────────┬────────┐
       │ 文獻搜尋│ 測量分析│ 製程模擬│
       └────────┴────────┴────────┘
                          ↓
            候選材料 + 製程參數推薦(小時級 vs 人類天級)
                          ↓
            人類工程師驗證 + 進入下一輪實驗
```

效益:把「發現缺陷 → 提出修補方案」的週期從天壓縮到小時。

### 3.4 2029 商用量子電腦目標

| 項目 | 含義 |

| **是** | 可解決材料科學 / 藥物發現 / 最佳化 / 密碼學中,**古典電腦無法實用解決**的問題 |

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 技術 | 技術解法 | 使用前提 | 副作用 | 預期效果 |
|---|---|---|---|---|
| **超導 qubit(IBM、Google)** | 用超導電路實現 qubit,以微波脈衝控制 | 需要稀釋致冷機(millikelvin) | qubit 數量多但相干時間短(μs~ms) | 目前最成熟的量子雲端服務(IBM Quantum) |
| **離子阱(IonQ)** | 用電磁場捕獲單一離子,雷射操控 qubit | 真空 + 雷射光學系統 | gate 速度較慢,但相干時間長 | 高保真度,適合特定演算法 |
| **光子量子(Xanadu)** | 用光子編碼 qubit,光學元件運算 | 室溫運作,但需精密光學 | 難以擴展大規模糾纏 | 適合特定 sampling 問題 |
| **拓樸量子(Microsoft Majorana)** | 拓樸保護 + Majorana 費米子 | 仍在早期驗證階段 | 2018 論文曾遭撤回,獨立驗證關鍵 | 若成功,長期擴展性最高 |

> **切入點差異**:
> - **超導 qubit** 採「**工業級 + 雲端**」:現有商業量子雲的主流,但每個 qubit 仍需大量錯誤更正
> - **離子阱** 採「**高精度 + 低 qubit 數**」:高保真但擴展難
> - **光子量子** 採「**室溫 + 特殊問題**」:免冷卻但僅限特定應用
> - **拓樸量子** 採「**根本性抗干擾**」:一旦驗證成功,擴展成本最低
