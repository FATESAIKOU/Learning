### 技術面: Spring AI 2.0.0 GA Available Now

- 為何選這篇: Spring AI 2.0.0 是 Java 生態系 AI 整合的生產級里程碑，用戶正在學習 Spring+AI 且 AxrossRecipe 使用 Spring Boot 技術棧。此次升級涉及 Spring Boot 4 基線、Jackson 3 遷移、null-safety 全面化、ChatClient Fluent API 等架構級變更，對現有專案的影響評估是本月不可迴避的技術決策。

- 深入方式:
  - 閱讀 Spring AI 2.0.0 官方 Upgrade Notes 與 Migration Guide，製作 AxrossRecipe 現有專案的影響範圍清單
  - 在本地環境建立 Spring AI 2.0.0 + Spring Boot 4.1 的 sandbox 專案，驗證 ChatClient Fluent API 與現有程式碼的相容性
  - 比較 Spring AI 2.0.0 的 Tool Calling 機制與用戶正在自製的 MCP (Model Control Platform) 的設計差異，評估是否有整合/替代空間
