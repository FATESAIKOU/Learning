# 10. サークレイスとゼンフォース、Salesforce領域で包括的提携を開始

**Source**: https://markezine.jp/news/detail/77152
**Author**: SalesZine編集部
**Date**: 2026/07/10
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

日本Salesforce生態系中，大企業與中小企業的導入支援長期處於割裂狀態。サークレイス（Circlace）擁有600家以上大企業導入實績，ゼンフォース（Zenforce）擁有200家以上中小企業支援實績。兩者合作解決的問題是：建立從中小企業到大企業的「無縫支援體制」，並提供AI代理（AI Agent）解決方案。

## 2. 這個問題為什麼會發生?(背景)

| 因素 | 說明 |
|------|------|
| Salesforce市場成熟化 | 日本Salesforce市場從「導入期」進入「最適化/定著期」 |
| AI代理需求崛起 | 企業從「使用CRM」轉向「AI驅動的CRM自動化」 |
| 大企業vs中小企業的服務斷層 | 大企業需要高度客製化，中小企業需要標準化快速導入 |
| 人才不足 | 雙方PM和SE的相互交叉派駐（cross-assign）解決人力瓶頸 |

## 3. 這個技術/政策是如何解決該問題的?

合作架構：

| 合作面向 | 具體內容 |
|----------|----------|
| 共同專案 | 已啟動7件共同專案，進行知識分享和生產力提升 |
| 營業共同計畫 | 從商機創造→成交→導入後定著的一貫支援 |
| 業種特化模板 | 共同開發行業別標準模板 |
| 人才交流 | PM和SE的相互交叉派駐 |
| AI解決方案 | 共同任務小組（Task Force）開發諮詢應對和提案業務效率化的AI方案 |
| 海外展開 | 長期以亞洲為中心的海外市場共同事業 |

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 |
|------|------|
| M&A（併購） | 直接收購對方公司，整合度最高但成本大 |
| 平台化（AppExchange） | 透過Salesforce生態系自然整合，但速度慢 |
| 合資公司 | 成立第三方合資公司專注特定市場 |
| 本案例的「緩やかな提携」 | 保持獨立性同時共享資源，風險較低 |

對用戶（Softbank、學習Spring+AI）的啟示：此合作模式是B2B SaaS生態系的典型擴張策略。Softbank作為Salesforce的日本重要合作夥伴，類似的大企業+中小企業協作模式可能影響其自身的CRM策略。AI代理在Salesforce領域的應用也是Spring+AI學習者的參考案例。
