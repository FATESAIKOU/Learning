# 11. カンヌライオンズ の主役に。インフルエンサーが広告の未来を変える理由

**Source**: https://digiday.jp/brands/creators-arent-just-in-marketings-entertainment-era-theyre-driving-it/
**Author**: Seb Joseph, Alyssa Mercante（翻訳・編集：杉本結美）
**Date**: 2026年7月
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

2026年坎城國際創意節（Cannes Lions）的核心轉變：創作者（influencer/creator）從廣告業的「配角」轉變為「主角」。品牌不再將創作者視為一次性廣告投放渠道，而是作為長期行銷策略夥伴、內容製作團隊的延伸，甚至是「組織的運作系統」的一部分。

## 2. 這個問題為什麼會發生?(背景)

| 驅動因素 | 說明 |
|----------|------|
| 數位平台碎片化 | 演算法多變，傳統廣告campaign不再有效觸達 |
| 信任轉移 | 消費者從不信任品牌廣告，但信任朋友推薦——創作者處於這條延長線上 |
| AI崛起 | AI處理重複性工作，人類創造力和真實性（authenticity）反而溢價 |
| IP經濟 | 品牌從「租用reach」轉向「建立自有IP」 |

具體案例：UTA（經紀公司）在坎城舉辦創作者晚宴——這個時段過去是CMO的專屬場合。OpenAI廣告部門主管參加坎城不是為了見品牌，而是為了見創作者。Bose的CMO甚至將創作者比作「創意代理商本身」。

## 3. 這個技術/政策是如何解決該問題的?

品牌與創作者的新型合作模式：

| 舊模式 | 新模式 |
|--------|--------|
| 單次campaign代言 | 6-12個月的常時運作合約 |
| 以follower數衡量 | 以authenticity和IP價值衡量 |
| 創作者=媒體版面的一行 | 創作者=人才+創意+製作公司+媒體+IP |
| 品牌主導訊息 | 品牌提供guardrail，創作者自主創作 |

L'Oréal CDMO：全球有50萬人代表品牌發言。Kraft Heinz CMO：CMO不是在租用reach，而是在「借用真實性」。Unilever CMO：這不是媒體問題，而是「需求如何被創造」的問題。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 |
|------|------|
| 品牌自建內容團隊 | 內部化創意製作，但缺乏創作者的authenticity |
| AI生成內容 | 成本低但缺乏真實性，坎城共識是「AI處理重複工作，人類保留創造力」 |
| 傳統廣告代理商 | 仍在但角色被擠壓，坎城海灘上UTA比廣告控股公司更有存在感 |
| 創作者自有品牌 | 創作者直接推出自有品牌（如MrBeast），跳過品牌方 |

對用戶（Softbank、行銷技術）的啟示：創作者經濟正在重塑B2C行銷的底層邏輯。對於B2B領域（如Salesforce生態系），類似的「信任中介」模式是否會出現？技術社群中的KOL（如GitHub明星開發者）可能扮演類似角色。
