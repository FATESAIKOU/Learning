# 17. ソニーの犬型ロボット『aibo』が國內販売終了　在庫限り

**Source**: https://robotstart.info/article/2026/06/26/382082.html
**Author**: ロボスタ編集部
**Date**: 2026/06/26
**Category**: 政治經濟

## 1. この技術/政策解決什麼問題?

本記事は製品の販売終了発表であり、新たに「解決」を提示するものではない。ソニーグループおよびソニーマーケティングが、犬型ロボット「aibo（アイボ）」ERS1000/W（アイボリーホワイト）の國內販売を在庫限りで終了すると発表したことを報じている。

**販売終了の範囲**:
- 対象: ERS1000/W 本體のみ
- 継続するサービス:
  - aiboベーシックプラン / aiboプレミアムプラン（クラウドサービス）
  - aiboケアサポートサービス
  - 関連アクセサリー・付屬品・本體部品販売
  - My aiboアプリ
  - aiboの治療（修理）
  - aiboドック

## 2. この問題為什麼會發生?(背景)

**aiboの歴史**:
- 初代aibo（ERS-110）: 1999年発売。世界初の家庭用エンターテインメントロボットとして話題に
- 2006年に一旦生産終了。ソニーの経営再建の一環としてロボット事業から撤退
- 2018年: 新型aibo（ERS-1000）として復活。AI・クラウド連攜・高度な感情表現を搭載
- 約8年間の販売を経て、2026年に再び國內販売終了

**パートナーロボット市場の競爭環境**:
- パナソニック「NICOBO」: 累計販売1萬體突破（2026年6月）、コミュニケーションロボットとして成長中
- GROOVE X「LOVOT」: 恐竜ウェアなどキャラクター展開でファンコミュニティを維持
- 會話AIロボット「Romi」: 音聲カスタマイズなど新機能を継続的に追加
- ソフトバンクロボティクス「Pepper」: 法人向けにシフト

**ソニーの戦略転換（推測）**:
- aiboは高価格帯（約20萬円＋月額サービス料）のニッチ製品であり、大量普及には至らなかった
- ソニーは現在、ゲーム・映畫・音楽・半導體など高収益事業に経営リソースを集中
- ロボット事業よりもAI・エンターテインメント領域への投資を優先していると推測される

## 3. この技術/政策是如何解決該問題的?

本記事は「解決」ではなく「撤退」の発表だが、以下の観點でソニーの対応を整理する:

**ソフトウェアサービスは継続**:
- ハードウェア販売を終了しても、既存ユーザー向けのクラウドサービス・修理・アプリは継続
- これはハードウェア製品のEOL（End of Life）におけるユーザー配慮として評価できる
- サブスクリプションモデル（aiboベーシックプラン/プレミアムプラン）による継続収益は維持

**パートナーロボット市場への示唆**:
- ハードウェア販売の終了≠サービス終了というモデルは、IoT・ロボティクス製品のライフサイクル管理として參考になる
- ただし、新規ユーザー獲得が止まることで、長期的にはサービス維持の経済的合理性が低下するリスクがある

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 製品 | アプローチ | 現狀 |
|------|-----------|------|
| aibo（ソニー） | プレミアム家庭用ロボット、ハード販売終了・サービス継続 | 國內販売終了 |
| NICOBO（パナソニック） | 低価格コミュニケーションロボット（約6萬円）、累計1萬體 | 成長中 |
| LOVOT（GROOVE X） | 感情豊かなパートナーロボット、キャラクター展開 | ニッチながら継続 |
| Pepper（ソフトバンクロボティクス） | 法人向けにピボット | 法人市場で継続 |
| Romi | 會話AI特化の小型ロボット、継続的な機能追加 | 成長中 |

**パートナーロボット市場の構造的課題**:
- 家庭用ロボットは「かわいい」「癒やし」という情緒的価値が中心で、実用的価値の提示が難しい
- ハードウェアの製造コスト・在庫リスクが大きく、ソフトウェア企業的なスケールが困難
- スマートスピーカー（Amazon Echo, Google Nest）のような実用デバイスとの差別化が課題

**ユーザー（Softbank AxrossRecipe）への示唆**:
- ソフトバンクグループの一員として、ロボティクス事業（Pepper, ソフトバンクロボティクス）の市場動向は間接的に関連
- ハードウェア製品のEOL戦略（サービス継続によるユーザー保護）は、SaaS/PaaSを扱う開発者として參考になる
- 「ハードウェア販売終了≠ブランド終了」という考え方は、プロダクトのライフサイクルマネジメント全般に応用可能
