# 06. 失意のうちに大学を去った彼女は「英雄」として帰ってきた…カリコがmRNAワクチンを接種された「歴史的な日」

**Source**: https://gendai.media/articles/-/168084
**Author**: 岸本忠三（大阪大学名誉教授）, 中嶋彰（サイエンス作家）
**Date**: 2026.07.12
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

本文記錄了mRNA疫苗共同發明者卡塔琳·卡里科（Katalin Karikó）在2020年12月18日回到賓州大學接種新冠疫苗的歷史性時刻。表面上是疫苗接種儀式，實際上解決的是**科學界對「非主流研究者」的結構性歧視問題**——卡里科曾因mRNA研究「缺乏前景」被賓州大學降職、削減經費，最終失意離開，加入德國BioNTech。

更深層的問題：學術界的評價體系（論文發表數、引用數、經費獲取能力）系統性地低估了基礎研究的長期價值。mRNA技術在被證明有效之前，被視為「沒有前途」的研究方向。

## 2. 這個問題為什麼會發生?(背景)

| 時間 | 事件 |
|------|------|
| 1980s-1990s | 卡里科在賓州大學進行mRNA研究，持續遭遇經費削減和降職 |
| 2013 | 卡里科離開賓州大學，加入德國BioNTech |
| 2020年初 | COVID-19全球大流行 |
| 2020/12/18 | 卡里科回到賓州大學接種mRNA疫苗，媒體聚焦 |
| 2023 | 卡里科與韋斯曼（Drew Weissman）共同獲諾貝爾生理學/醫學獎 |

日本在疫情初期的對照：2020年春，日本「舊世代專家」過度謹慎地預測「疫苗最快也要2021年秋冬季才能完成」，但mRNA疫苗在2020年底已展現90%以上的預防效果。這反映了日本在mRNA技術上的落後認知。

## 3. 這個技術/政策是如何解決該問題的?

卡里科的「解決方案」不是政策性的，而是**個人堅韌 + 私部門接納**的模式：

- **BioNTech的接納**：德國生技公司提供了學術界拒絕的資源和信任
- **mRNA技術的驗證**：COVID-19大流行提供了前所未有的驗證場景，mRNA疫苗在一年內完成從序列發布到緊急授權的全程
- **賓州大學的「補救性榮譽」**：大學在意識到疫苗的巨大成功後，迅速將卡里科塑造為「英雄」，舉辦全國媒體聚焦的接種儀式

卡里科本人選擇接受大學的邀請，而非在德國接種——文章稱之為「成熟的選擇」。她將過去的委屈吞下，以科學成就本身回應了曾經的冷遇。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 |
|------|------|
| 基礎研究長期基金（不以論文數考核） | Howard Hughes Medical Institute 模式：給研究者長期自由探索資金 |
| 企業-學界「旋轉門」 | 卡里科模式：學界做基礎研究，企業做應用轉化 |
| 失敗研究獎勵機制 | 鼓勵發表「負面結果」，減少對「熱門方向」的從眾 |
| 日本對照：審良静男 | 同書提及的日本免疫學家，為卡里科的論文發表鋪路，但日本國內對mRNA的投資仍不足 |

對用戶（即將轉管理者）的啟示：卡里科的故事是「人才管理」的經典反面教材。賓州大學的評價體系錯失了諾貝爾級人才。作為管理者，如何識別和保護「非主流但具突破潛力」的團隊成員，是核心課題。
