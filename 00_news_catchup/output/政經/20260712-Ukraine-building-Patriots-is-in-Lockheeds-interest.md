# 05. Ukraine building Patriots is in Lockheed's interest, McCaul says

**Source**: https://fortune.com/2026/07/11/ukraine-patriot-missile-defense-russia-lockheed-rtx/
**Author**: Christina Ruffini, David Gura, Bloomberg
**Date**: July 11, 2026
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

川普在NATO峰會期間承諾向烏克蘭發放愛國者飛彈防禦系統的製造許可證。這解決的核心問題是：烏克蘭長期以來攔截飛彈數量不足，無法有效防禦俄羅斯彈道飛彈攻擊。澤倫斯基多年來懇求美國和盟友提供更多攔截飛彈，但供應始終受限。

眾議員Michael McCaul（德州共和黨、眾院外交委員會成員）在烏克蘭接受採訪時明確表示，洛克希德馬丁「有充分理由」授權烏克蘭生產愛國者攔截飛彈，並稱「烏克蘭人可以做得更快，甚至更好」。

## 2. 這個問題為什麼會發生?(背景)

| 因素 | 說明 |
|------|------|
| 戰爭持續4年+ | 俄羅斯全面入侵已超過4年，彈道飛彈攻擊持續摧毀城市 |
| 攔截飛彈供應瓶頸 | 美國和盟友的生產線無法滿足烏克蘭的消耗速度 |
| 川普政策轉向 | 從「美國優先」轉向「授權盟友自產」，降低美國直接負擔 |
| 洛克希德的商業利益 | 授權生產仍收取授權費，且可從烏克蘭的實戰經驗中學習改進 |

McCaul的邏輯鏈：川普要授權 → 洛克希德配合符合自身利益 → 烏克蘭獲得自主生產能力 → 美國減少直接軍援負擔。這是一個「川普式的交易思維」——不是無償援助，而是授權生產的商業安排。

## 3. 這個技術/政策是如何解決該問題的?

**技術授權模式**：

- 愛國者系統涉及洛克希德馬丁和RTX（雷神）兩家公司的技術
- 授權烏克蘭本土生產意味著技術轉移、生產線建立、品質管控
- McCaul暗示洛克希德可從中獲益：「洛克希德可以從烏克蘭人那裡學到關於自己攔截飛彈的知識——如何改進、如何更快製造」

**戰略意義**：

- 烏克蘭從武器「消費者」升級為「生產者」
- 縮短供應鏈：從美國→烏克蘭的數週運輸變為本土即時生產
- 降低政治風險：不再受美國國會撥款辯論的影響

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 案例 | 比較 |
|------|------|------|
| 直接軍援（傳統模式） | 美國對以色列的鐵穹系統 | 政治依賴性高，供應量受限 |
| 授權生產（本案例） | 日本授權生產F-35 | 技術門檻高，但自主性強 |
| 聯合開發 | 日英義GCAP次世代戰機 | 分攤成本，但開發週期長 |
| 替代系統採購 | 烏克蘭採購以色列或韓國防空系統 | 系統整合複雜 |
| 本土自主研發 | 烏克蘭無人機產業 | 已在進行，但飛彈防禦技術門檻極高 |

對用戶（關注地緣政治、日本防衛產業）的啟示：此模式若成功，可能成為美國盟友防衛合作的新範本。日本同樣面臨飛彈防禦需求（北韓威脅），授權生產模式可能擴展至亞太。Softbank雖非直接相關，但防衛科技投資（無人機、AI防禦）是潛在成長領域。
