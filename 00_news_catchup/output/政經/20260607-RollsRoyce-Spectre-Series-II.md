# 32. ロールスロイスの電動スーパークーペ『スペクター シリーズII』発表 (原文)

**Source**: https://response.jp/article/2026/06/07/412359.html
**Author**: Response 編集部
**Date**: 2026/06/07
**Category**: 政治經濟

## 1. 這款產品解決什麼問題?

Rolls-Royce 於 2026/06/02 發表電動超級轎跑 Spectre Series II 與 Black Badge Spectre Series II,主要升級為:航續 +18% 至 628km (WLTP)、充電時間 -14%、出力提升 (Black Badge 達 500kW / 1100Nm,史上最強 RR)、新增 Bespoke 工藝選項。

| 規格 | Spectre Series II | Black Badge Series II |
|---|---|---|
| 航續 (WLTP) | 628 km (+18%) | (同 Series II) |
| 充電時間 | -14% | (同 Series II) |
| 最大出力 | 442 kW | 500 kW (インフィニティ模式) |
| 最大扭力 | 1015 Nm | 1100 Nm (スピリテッド模式) |
| 特殊定位 | 主力 | RR 史上最強 |

## 2. 為什麼會發生?(背景)

### 2.1 Rolls-Royce 電動化戰略

| 時間 | 事件 |
|---|---|
| 2011 | BMW 推出電動實驗車, RR 開始探索 |
| 2022/09 | Spectre 全球首發 (首款純電 RR) |
| 2023-2024 | Spectre 全球交車,躋身 RR 第 2 大暢銷車 |
| 2025 | Spectre 維持「世界第 2 多銷售 RR」地位 |
| 2026/06 | Series II 小改款 |
| 目標 | 2030 年前全產品線電動化 |

### 2.2 超豪華電動車的市場結構

| 品牌 | 純電車款 |
|---|---|
| Rolls-Royce | Spectre |
| Bentley | 推遲電動化 (2025 撤回) |
| Lamborghini | Revuelto PHEV, 純電 Lanzador 2028 |
| Ferrari | 首款 EV 2025 底發表 |
| Aston Martin | DB12 PHEV, 純電 2026+ |
| Maserati | GranCabrio Folgore, MC20 Folgore |

### 2.3 為何 RR Spectre 成功?

| 因素 | 機制 |
|---|---|
| 客戶用車場景 | 推測:車主平均擁有 7 輛車,年走 6,500km,多為自宅充電 |
| 駕駛體驗 | 電車的低噪音 + 平順性,完美匹配「Chauffeur-driven + 自駕」雙場景 |
| 維修簡化 | 電動 powertrain 維修頻率遠低於 V12 |
| 品牌象徵 | 「電動 Rolls-Royce」本身就是身分象徵 (永續 + 傳統) |
| Bespoke | Series II 強化訂製能力 (車主獨佔感) |

## 3. Spectre Series II 如何運作?

### 3.1 機械改進

```text
[電池組]
  重新設計電池芯技術
  + 容量提升 → 航續 +18% (390 miles / 628km WLTP)
  + 充電時間 -14%

[動力]
  Series II: 442 kW / 1015 Nm
  Black Badge: 500 kW (Infinity) / 1100 Nm (Spirited)
  + RR 史上最強量產車

[結構]
  推測沿用 102 kWh 電池組 + 雙馬達四驅
  + 鋁合金空間架構 (與 BMW i7 共用平台)
```

### 3.2 Bespoke 工藝新增

| 項目 | 內容 |
|---|---|
| Duality Twill (新材質) | 竹子原料レーヨン,首次用於 Spectre |
| 顏色 | ライラック、巧克力、黒、新增セージ |
| 刺繍 | 50 種以上糸色, 25 小時完成, 260 萬針 |
| Placed Perforation | 7 萬 8,138 孔的藝術圖案 |
| ベニア (Blindled Walnut) | 廢棄無果ウォルナット + ユーカリ纖維殘渣,「Tiger Stripe」 |
| 車色 (新色) | Ethereal Blue (Series II 專屬) |
| 輪圈 | 23 吋鍛造多面設計,每只 6 小時手工 |
| Interior | Illuminated Fascia (8,108 像素イルミ)、航空儀錶風時鐘 |
| Spirit of Ecstasy | 不鏽鋼無垢材雕製 (車內擺飾) |

### 3.3 商業模式

| 面向 | 細節 |
|---|---|
| 售價 | 推測:£300,000+ (Spectre),£400,000+ (Black Badge) |
| 銷售方式 | Bespoke 訂製為主, 等待期 6-12 個月 |
| 銷售排名 | 2025 年 RR 銷售第 2 名 (僅次於 Cullinan) |
| 客戶特性 | 平均 7 輛車,年走 6,500 km,自宅充電,單獨駕駛 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **RR Spectre 純電 (本案)** | 豪華電車 + 訂製工藝 | Spectre Series II | 售價高,市場小 |
| **Bentley 推遲電動化** | 先 PHEV,2030 後再純電 | Continental GT PHEV | 落後對手 |
| **Lamborghini V12 PHEV** | 保留引擎 + 電動輔助 | Revuelto | 重量增加 |
| **Ferrari 純電 (2025+)** | 首款 EV 2025 | Ferrari EV | 設計爭議 |

| **Mercedes EQS** | 純電 S-Class 級距 | EQS | 設計保守 |
| **Rolls-Royce 油電混合 (未來)** | 保留引擎選項 (推測) | (未發表) | 品牌矛盾 |
| **氫燃料電池 (推測)** | 氫電 vs 鋰電 | Toyota Mirai, BMW iX5 | 基礎建設不足 |

### 對使用者的意涵 (超豪華電動化 + 訂製經濟)

- **超豪華品牌電動化** 確認電動車不是「平價品」,反而強化品牌
- 對 Softbank/管理者:理解「電動化」對不同價位品牌的不同意義
- 對日本/台灣:超豪華車市場規模小但象徵意義大,值得追蹤
- 推測:Series II 強化 Bespoke,顯示「客製化」是超豪華品牌的終極護城河

---

**對汽車業 + IT 業的啟示**:
- 「電動化」不是工業邏輯的延續,而是「品牌敘事」的重建
- 超豪華品牌電動化顯示:**技術變革反而強化傳統品牌** (與 Toyota 章男擔心的相反)
- 對管理者:理解「產品升級」不只是規格,更是「敘事升級」(Series II = 故事的第二章)
- 訂製經濟 (Bespoke) 的 25 小時 + 260 萬針,顯示「手作時間」是新奢侈品
- 對台灣:Gogoro 的「訂閱 + 換電」是另一種 Bespoke 思維
