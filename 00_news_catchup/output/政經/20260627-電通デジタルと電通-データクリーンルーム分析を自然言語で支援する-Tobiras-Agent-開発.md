# 10. 電通デジタルと電通、データクリーンルーム分析を自然言語で支援する「Tobiras Agent」開発

**Source**: https://markezine.jp/news/detail/77053
**Author**: MarkeZine編集部
**Date**: 2026/06/26
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

データクリーンルーム（Data Clean Room, DCR）を用いた広告効果検証において、分析にはSQLなどのプログラミング言語の専門知識が必須であり、以下の課題が顕在化していた:

| 課題 | 具體影響 |
|------|----------|
| 人材不足 | DCR分析を実行できるSQL人材が限られ、業務が屬人化 |
| 意思決定スピードの低下 | 分析依頼から結果取得までのリードタイムが長い |
| 高度な分析の斷念 | 運用負荷が高く、本來実施したいクロス集計やセグメント分析を斷念 |

「Tobiras Agent」は、自然言語による対話でこれらの分析を実行可能にし、専門知識に依存しない分析環境を構築する。

## 2. この問題為什麼會發生?(背景)

**サードパーティCookie規制の進行**:
- Google ChromeのサードパーティCookie廃止（段階的進行中）、Apple ITP強化により、従來のユーザー単位トラッキングが困難に
- 広告主・メディアはプライバシー保護と効果測定の両立を迫られている

**DCRの普及とボトルネック**:
- DCRは各社が保有する1stパーティデータを暗號化・匿名化した狀態で突合・分析できる仕組みで、Cookieレス時代の広告計測の新基盤として注目
- しかしDCRの操作にはSQLが必須であり、マーケティング擔當者が直接データを觸れないという構造的ギャップが存在

**電通の先行投資**:
- 電通デジタルは2022年に分析基盤「Tobiras」を発表済み。複數のDCR環境を一元管理するプラットフォームとして展開
- 今回の「Tobiras Agent」はその発展形であり、AIエージェントによる自然言語インターフェースを追加

## 3. この技術/政策是如何解決該問題的?

「Tobiras Agent」の処理フロー:

```
[ユーザー入力] 自然言語で分析目的・條件を入力
       ↓
[AIエージェント] 課題設定 → 分析クエリ(SQL)生成
       ↓
[実行] DCR上でクエリ実行
       ↓
[結果取得] データ取得 → 內容の読み解き
       ↓
[出力] 分析結果を自然言語で提示
```

**技術的ポイント**:
- 自然言語→SQL変換にLLMを活用（推測: GPT-4クラスのモデルを使用したText-to-SQLパイプライン）
- 第1弾としてAmazon Marketing Cloud（AMC）に対応。Amazon広告のデータ分析基盤との連攜を実裝
- 複數DCRを一元的に運用できる設計で、今後のマルチプラットフォーム展開を想定

**期待される効果**:
- 分析リードタイムの短縮（従來の數日→數時間レベル）
- マーケター自身によるセルフサービス分析の実現
- 広告主企業のROI最大化と施策精度の向上

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| アプローチ | 代表例 | 特徴 | Tobiras Agentとの違い |
|------------|--------|------|----------------------|
| 汎用Text-to-SQLツール | GitHub Copilot, ChatGPT Code Interpreter | 汎用的なSQL生成が可能だが、DCRスキーマに非対応 | DCR専用設計でスキーマ最適化済み |
| マーケティング特化AI分析 | Adjust「Growth Copilot」 | アプリ分析に特化した自然言語クエリ | 広告効果測定（DCR）に特化 |
| ノーコードDCR分析 | 各DCRベンダーのGUIツール | ドラッグ&ドロップで分析構築 | 自然言語入力の方が學習コスト低い |
| データ分析自動化 | Shopifyの自然言語ワークフロー生成 | ECデータ分析の自動化 | 広告データ分析にフォーカス |

**競爭環境の考察**:
- 博報堂DYホールディングスも同時期にChatGPT上の広告設計・アセット生成支援機能を発表しており、広告會社間でのAIエージェント開発競爭が加速
- 電通グループは「PSDCA」フレームワークを発表済みで、AI戦略を構想から実裝フェーズへ移行中
- ユーザー（Softbank AxrossRecipe）にとっては、広告効果測定の効率化という観點で、マーケティング予算の最適化に貢獻する技術トレンドとして注視すべき領域
