# 12. 法医学者の解剖で判明した「死亡推定時刻」の謎…男性が生命保険の払われない免責期間に死を選んだ切ない理由 (原文)

**Source**: https://president.jp/articles/-/114205
**Author**: 高木 徹也(東北医科薬科大学教授、法医学者)
**Date**: 2026/06/07
**Category**: 政治經濟

## 1. 這個制度解決什麼問題?

日本生命保險的「**免責期間 (免責期間 / 告知義務違反除外責任期間)**」機制:投保後若於短期間內(多為 1-3 年)發生**自殺**,保險公司可不給付保險金,僅退還已繳保費。本文是法醫學者高木教授以實際檢案案例,說明死後經過時間 (post-mortem interval, PMI) 推定在「**免責期間是否已過**」爭議中的關鍵作用。

| 制度元件 | 功能 |
|---|---|
| 免責期間 (waiting period) | 防止「帶病/帶意圖投保」逆選擇 (adverse selection) |
| 自殺免責條款 | 防止道德危險 (moral hazard),兼顧遺族情感 (退還保費) |
| 法醫死後經過時間推定 | 在「發現時刻 vs 死亡時刻」落差上提供科學證據 |
| 死亡診断書 / 死体検案書 | 法定文件,記載推定死亡日時 |

## 2. 這個問題為什麼會發生?(背景)

### 2.1 為何要設計免責期間?

- **逆選擇防範**:若允許「診斷出絕症後大量投保」,保險池會被高風險者吃垮
- **自殺免責**:日本《保險業法》與各家生命保險約款規定,通常契約生效後 1-3 年內自殺不給付(防止「保險金動機」自殺)
- **國際比較**:美國多數州採 2 年「contestability period」,可整份契約否決;日本則普遍採「自殺免責」條款

### 2.2 法醫 vs 臨床的死亡時刻判定差異

| 領域 | 死亡時刻判定 |
|---|---|
| 臨床医学 (病院) | 醫師依心停止時刻記錄,可精準到分 |
| 法医学 (検案) | 死体現象(直腸温、死後硬直、屍斑、腐敗)綜合推定,**有 ±2 小時誤差** (48h 內);超過 3 日誤差可達 1 日 |
| 法律效果 | 免責期間是否屆滿,完全依「推定死亡時刻」決定 |

> 高木教授原話:「亡くなってから 48 時間以内にご遺体をみることができれば、2 時間ほどの誤差で死後経過時間を出すことができる」

### 2.3 本案背景脈絡

- 保險公司員工男性(對契約內容熟稔)
- 與妻不睦、家庭內別居
- 跳樓自殺,**發現日 = 免責期滿翌日**
- 若死亡發生於發現日 → 給付;若為前日 → 不給付
- 警方後續調查:男性刻意選擇「期滿前一天」,意圖不讓妻子繼承

## 3. 這個機制(法醫判定 + 免責條款)如何運作?

### 3.1 法醫 PMI 推定的科學流程

```text
現場
  ↓
直腸温測定 (cooling curve, 死后 1-12h 較準)
  + 死後硬直 (rigor mortis) 進程
  + 屍斑 (livor mortis) 固定程度
  + 角膜混濁、眼球變化
  + 環境氣温調整
  ↓
綜合推算 PMI (給出區間,非單一點)
  ↓
「発見前日 ○時〜○時」形式回答
```

### 3.2 案例決策點

| 證據 | 高木教授判斷 |
|---|---|
| 直腸温 | 與「発見日」不符 |
| 死後硬直進程 | 與「発見前日傍晚~當日凌晨」一致 |
| 屍斑固定 | 支持前日晚間死亡 |
| 綜合 | 死亡發生於「免責期間內」 → 不給付 |

### 3.3 家屬的施壓與法醫的抵抗

- 家屬主張:「保険取り扱い職員が免責期間内に自殺するはずがない」「死後経過時間には誤差がある」
- 法醫回應:「あらゆる所見からみて、発見当日に亡くなったとはとうてい考えられません」→ **拒絕更改死亡診断書**
- 制度意義:法醫的科學獨立性 = 保険会社 vs 遺族糾紛的最終仲裁

## 4. 是否存在解決類似問題的其他制度 / 思考方式?

| 替代制度 | 機制 | 優點 | 缺點 |
|---|---|---|---|
| **日本現行:自殺免責條款** | 契約生效 1-3 年內自殺不給付 | 防止道德危險,簡明 | 「邊界日」爭議多,本文即一例 |
| **美國 Contestability period** | 投保後 2 年內保險公司可整份否決 | 公司彈性大 | 消費者保護弱 |
| **英國 Suicide exclusion (12 月)** | 較短免責期 | 對遺族友善 | 逆選擇風險上升 |
| **無免責制度** | 自殺一律給付 | 對家屬最友善 | 道德危險高、保費上漲 |
| **「推定時刻區間 + 保險契約模糊條款」** | 約款明訂 ±X 小時歸於「免責期滿後」 | 爭議降低 | 法醫專業裁量縮減 |
| **法醫第三方鑑定委員會** | 由學會專家組獨立小組,覆蓋爭議案 | 科學中立性強化 | 制度成本高 |

### 對使用者的意涵 (日本 IT 業管理者)

- **人壽保険 + 法醫制度** 是日本保險商品的基礎設施,**理解免責期約款**是員工福利設計的基本功
- 推測:在 Softbank 集團福利設計中,團體生命保険 (GL) 的「自殺免責期間」是契約條款必要審閱項
- **跨國派駐/轉勤** 時,各國免責制度差異會影響保險理賠,需特別注意美國 contestability 與日本 suicide exclusion 的差異
- 法醫 PMI 判定的「區間思維」(給範圍不給點) 是 IT 不確定性管理的隱喻 — 任何估計都該有「信賴區間」

---

**對台灣/日本人壽保險契約的具體提醒**:
- 自殺免責通常 1-3 年,但各公司約款不同
- 高齢投保時,健康告知與等待期 (90-180 日) 是另一條戰線
- 法醫判定在「意外 vs 自殺」理賠爭議中具關鍵作用
