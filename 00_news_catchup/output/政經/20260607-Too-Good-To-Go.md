# 29. 「Too Good To Go」が創る新たな購買体験 (原文)

**Source**: https://markezine.jp/article/detail/50790
**Author**: 小口 裕 (ニッセイ基礎研究所 主任研究員)
**Date**: 2026/06/05
**Category**: 政治經濟

## 1. 這個商業模式解決什麼問題?

丹麥 Too Good To Go(TGTG)是全球最大食品ロス削減 app,2026/01 正式登陸日本,3.5 個月內日本註冊用戶突破 50 萬,加盟店約 300+,涵蓋 Krispy Kreme、Lawson、Don Quijote、かっぱ寿司等。本文分析 TGTG 如何透過「お得 + エンタメ」,把社會議題包裝成自然消費體驗。

| 服務模式 | 內容 |
|---|---|
| 提供者 | 店鋪將當日剩餘食品包成「Surprise Bag」上架 |
| 消費者 | app 預約 + 店取 + 中身到場才知道 |
| 價格 | 推測:原價 30-50% off |
| 涵蓋 | 21 國、1.2 億用戶、20 萬店家、6 億食削減 (2026/04) |
| 日本 | 2026/01 正式 launch → 5 月 50 萬用戶 |

## 2. 為什麼會發生?(背景)

### 2.1 日本食品ロス的規模與政策

| 項目 | 數據 |
|---|---|
| 日本食品ロス年量 | 約 472 萬噸 (2022 推算) |
| 來源 | 事業系 (business) 275 萬噸、家庭系 197 萬噸 |
| 法律 | 食品ロス削減推進法 (2019 成立,2024 修訂) |
| 政策 | 環境省、農林水産省、消費者廳三方協作 |
| 目標 | 2030 年家庭系半減、事業系 50% 削減 |

### 2.2 為何 TGTG 模式「不易複製到日本」?

| 歐洲條件 | 日本條件 |
|---|---|
| 環保意識高 | 「お得」動機 > 「環保」動機 |
| 外食比例高 | 自炊比例高,食材管理較嚴謹 |
| 店面密度高 | 車社會,店取較不便 |
| 法規限制少 | 食品表示/期限法規嚴格 |
| 補貼積極 | 補貼政策尚在建立中 |

### 2.3 TGTG 日本成功關鍵 (推測)

| 策略 | 機制 |
|---|---|
| 從「社會議題」轉向「商業價值」 | 「おいしい選択。」slogan 把環保降為附加價值 |
| B2B 切入 | 先攻 Krispy Kreme、Lawson 等大品牌,後續消費者跟進 |
| 中身 surprise | 把消費轉為遊戲/体験 (宝盒感) |
| 價格誘因 | 對抗通膨,「得划算」是核心驅動 |
| 對店鋪雙贏 | 廢棄成本降低 + 新客流入 (Krispy Kreme 案例) |

## 3. TGTG 商業模式如何運作?

### 3.1 價值鏈設計

```text
店鋪端:
  剩餘食品(原本廢棄)
  → Surprise Bag 包裝 (店鋪自定)
  → app 上架 (時間窗 + 數量限制)
  → 消費者預約
  → 店取交付
  → 收益入帳 (廢棄成本變營收)

消費者端:
  開 app
  → 搜尋附近店家
  → 預約 Surprise Bag
  → 店取 (時間窗內)
  → 打開驚喜 (surprise 體驗)
  → 拍照分享 (社群擴散)
```

### 3.2 店鋪端效益 (Krispy Kreme 案例)

| 效益 | 量化 |
|---|---|
| 廢棄成本削減 | 直接損益改善 |
| 新客流入 | TGTG 用戶首次到店,後續轉單 |
| 品牌好感 | 環保形象加分 |
| 庫存管理 | 即時動態調整生產量 |
| 推測 | TGTG 用戶 LTV > 一般 user |

### 3.3 消費者心理學

| 驅動 | 9 割「お得・エンタメ」, 1 割「サステナ」 |
|---|---|
| 核心 | 「おいしい体験」(好吃體驗) 為前提 |
| 次要 | お得 (划算) + エンタメ (驚喜) |
| 隱性 | 社會貢献感 (附加而非主軸) |
| 風險 | 中身不明的「賭け感」可能反彈 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **TGTG Surprise Bag (本案)** | 店家剩食 + 用戶驚喜 + 商業雙贏 | Too Good To Go | 中身不明,品質不均 |
| **Kuradashi.jp** | 滯銷品特賣 (主動式) | Kuradashi | 與新品價格衝突 |
| **TABLE FOR TWO** | 餐廳捐贈機制 (公益型) | TABLE FOR TWO | 不直接處理剩食 |
| **直接捐贈 (Food bank)** | 店家捐給 food bank | 食品銀行 | 物流/法规複雜 |
| **動態定價 (Yield pricing)** | 過期前折扣 | Starbucks, 7-11 | 主要解決期限問題 |
| **訂閱制剩食 (Imperfect Foods)** | 訂閱不完美食材 (美國) | Imperfect Foods | 僅限特定商品 |
| **業界 ERP 整合** | 預測 + 自動降價 AI | 沃爾瑪 AI 訂購 | 需規模化 |
| **App 內拍賣** | 用戶出價競標 | 推測:Yahoo オークション | 法規/公平性 |
| **AI demand forecasting** | 預測需求,減少剩食 | セブン-イレブン AI | 需數位基礎建設 |

### 對使用者的意涵 (永續商業 + 消費心理)

- **社會議題商業化** 需以「お得 + 娛樂」為主軸,環保只能為附加價值
- 對 Softbank/管理者:企業 CSR/ESG 策略應避免「說教型」,採用「共贏型」設計
- 對日本/台灣:TGTG 已成為食品業界重要通路,可作為 ESG 投資標的
- 對 Z 世代消費者:「社會貢獻感」需結合「實質體驗」才會買單

---

**對日本/台灣企業的具體建議**:
- 餐飲/零售業者可評估引進 TGTG,作為庫存管理工具
- ESG 報告可引用 TGTG 數據作為量化成果
- 對管理者:理解「環保」議題的傳達方式,直接說教易引起反感
- 推測:2026 下半年 TGTG 日本用戶將突破 200 萬,進入主流應用階段
