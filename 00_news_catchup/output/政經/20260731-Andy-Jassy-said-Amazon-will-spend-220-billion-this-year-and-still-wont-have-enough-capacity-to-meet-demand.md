# 07. Andy Jassy said Amazon will spend 220 billion this year and still wont have enough capacity to meet demand

**Source**: https://fortune.com/2026/07/30/andy-jassy-amazon-capex-demand-aws-pga-tour/
**Author**: Amanda Gerut(Fortune)
**Date**: 2026-07-30
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

Amazon CEO Andy Jassy 在 Q2 2026 財報會議上揭露三項關鍵訊息,解決的是市場對「AI 基礎設施投資是否過度」的核心疑慮:

| 問題 | Amazon 的回答 |
|------|--------------|
| **AI 資本支出是否泡沫?** | 2026 年資本支出上修至 **$2200 億**,仍「不足以滿足需求」,2027 亦然 |
| **AWS 成長是否放緩?** | Q2 營收 $422 億、YoY +37%,為 18 季以來最快增速,連續 5 季加速 |
| **自由現金流轉負是否警訊?** | FCF 轉為 -$76 億(去年同期 +$182 億),主因設備採購 YoY 增 $661 億,屬 AI 投資 |

核心訊息:AI 需求遠超供給,資本支出是回應需求的理性投資而非盲目擴張。

## 2. 這個問題為什麼會發生?(背景)

- **Hyperscaler 軍備競賽**:主要雲端業者合計承諾 $8000 億+ 用於資料中心與 AI 基礎設施,投資人焦慮回報時點。
- **AWS 營運數據**:

  | 指標 | Q2 2026 | YoY |
  |------|---------|-----|
  | AWS 營收 | $422 億 | +37%(18 季最快) |
  | AWS 營業利益 | $166 億 | +64% |
  | AWS 營業利益率 | 39.4% | +6.5pp |
  | AWS 年化營收 | $1690 億 | Fortune 500 排名第 24 |
  | AWS 積壓訂單 | $4960 億 | — |
  | AWS 廠房設備 | $2230 億(Q1) | 較前季 $1900 億大幅增加 |

- **推論工作負載成長**:Jassy 指出「more and more companies are bringing their inference workloads to production」,客戶傾向將推論部署在與既有工作負載、資料同處的位置,而 AWS 是多數企業既有雲端所在。
- **Bedrock 表現**:Q2 客戶在 Bedrock(整合 Anthropic、Meta、OpenAI 模型)的花費超過先前所有季度總和。Jassy 表態「沒有單一模型統治世界」,不會自建 frontier model 也能成功。
- **85% 全球 IT 支出仍在地端**:Jassy 預期 10-20 年內此比例將翻轉,AWS 將取得企業雲端遷移「lion's share」。
- **電力 capacity 計畫**:AWS 計畫 2027 年底電力 capacity 較 2025 年翻倍。

## 3. 這個技術/政策是如何解決該問題的?

Amazon 的戰略邏輯:

```
需求訊號(積壓 $4960 億)
  → 加碼資本支出至 $2200 億
  → 擴建資料中心 + 電力 capacity 翻倍
  → Bedrock 多模型策略(避免被單一模型綁架)
  → 等待 85% on-prem 逐步遷移
  → 長期 lion's share
```

| 戰略選擇 | 目的 |
|----------|------|
| **不自建 frontier model** | 避免與客戶(OpenAI/Anthropic)競爭,定位為中立平台 |
| **多模型策略(Bedrock)** | 滿足客戶「開放模型 + 專有模型」混合需求 |
| **龐大資本支出** | 搶佔供給不足窗口,建立規模壁壘 |
| **電力 capacity 長期規劃** | 預見 AI 資料中心用電指數成長,提前佈局 |
| **營業利益率擴張同時擴張** | 證明規模經濟存在,反駁「投資拉低利潤」擔憂 |

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 框架 | 機制 | 對比 |
|------|------|------|
| **微軟 Azure + OpenAI 戰略聯盟** | 深度綁定单一前沿模型,但同時支援其他模型 | 與 Amazon 多模型策略方向類似,但綁定程度更深 |
| **Google Cloud + Gemini** | 自建模型 + 雲端整合,差異化在 AI/ML 工具鏈 | 自建模型策略與 Amazon 相反 |
| **主權雲/混合雲** | 本地 + 公有雲混合,降低 vendor lock-in | 對應 Jassy 所言「85% 仍在地端」的市場機會 |
| **專用 AI 晶片(Trainium/Inferentia)** | Amazon 自建晶片降低對 NVIDIA 依賴 | 推測:資本支出中含晶片研發,降低長期成本 |
| **核能/再生能源 PPAs** | 科技巨頭簽訂長期清潔能源合約 | 應對資料中心電力需求與碳排壓力 |
| **邊緣推論** | 部分推論下沉至邊緣,降低雲端壓力 | 與「集中化超大規模」策略不同,但可作補充 |

**對用戶的啟示**:

1. **AI 基礎設施供不應求至少持續至 2027**——AxrossRecipe(使用 GCP/GKE)在規劃 AI 推論部署時,需預留容量緩衝,可能面臨 GPU/TPU 取得排隊。
2. **多模型策略是企業採購原則**——Bedrock 的成功證明企業不想被單一模型綁架。團隊在選擇 AI 服務時,應優先考慮可切換的抽象層(如 Spring+AI 的模型抽象、MCP 的工具協議),避免 lock-in。
3. **「85% on-prem」的遷移機會**——Jassy 點出企業 IT 仍有大量在地端,意味未來 10-20 年雲端遷移是長期趨勢。AxrossRecipe 若能協助客戶從地端遷移至雲端 + AI,是長期商機。
4. **資本支出的兩面性**:Amazon FCF 轉負但股價漲 9%,市場接受「投資 = 未來成長」邏輯。對孵化新創而言,在解釋 AI 工具/基礎設施投資 ROI 時,可參考「積壓訂單 + 需求超供給」的論述框架,而非僅以短期成本衡量。
5. **Amazon 對 Anthropic 投資貢獻 $534 億非營業利益**——點出「大型科技公司透過投資 AI 新創分享成長」的財務模式,此模式在 IPO 後可能改變,值得關注對 Anthropic 等供應商策略的影響。
