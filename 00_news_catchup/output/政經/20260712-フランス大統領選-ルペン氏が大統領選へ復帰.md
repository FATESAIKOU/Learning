# 02. 【フランス大統領選】ルペン氏が大統領選へ復帰、極右・RN政権誕生でフランス財政とユーロに迫る新たな市場リスク

**Source**: https://jbpress.ismedia.jp/articles/-/95884
**Author**: 唐鎌大輔
**Date**: 2026年7月
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

2027年春法國大統領選舉的政治格局正在重組。極右政黨國民聯合（RN）領袖馬琳·勒龐（Marine Le Pen）於7月7日正式宣布參選，同日控訴審判決將被選舉權停止期間從一審的5年縮短至1年3個月，且從一審判決日起算，勒龐的被選舉權已正式恢復。這解決了RN陣營的最大不確定性——誰來代表極右勢力出戰。

更深層的問題是：馬克宏退場後，法國中道勢力缺乏能同時對抗極右和極左的統一候選人。ECB總裁拉加德暗示可能提前辭職參選，反映中道陣營的焦慮。

## 2. 這個問題為什麼會發生?(背景)

| 因素 | 說明 |
|------|------|
| 馬克宏任期屆滿 | 2027年無法連任，中道權力真空 |
| RN支持率高漲 | 勒龐或現黨魁巴爾德拉（Bardella）民調均領先 |
| 司法判決逆轉 | 一審5年公民權停止→控訴審縮至1年3個月，勒龐得以參選 |
| 拉加德「待望論」 | ECB總裁暗示可能參選，反映中道陣營人才荒 |
| 反EU情緒 | 勒龐反EU立場與法國國內右傾化趨勢共振 |

關鍵轉折：2025年3月一審判決勒龐5年公民權停止，當時被視為RN的致命打擊。但控訴審大幅縮短刑期，且勒龐已上告至最高法院，在上告期間電子腳鐐判決不生效——她可以自由競選。

## 3. 這個技術/政策是如何解決該問題的?

勒龐的策略是**司法戰 + 民意戰並行**：

- **司法面**：透過上告延緩刑罰執行，確保選舉期間行動自由。控訴審的減刑為其提供了合法性背書。
- **政治面**：利用馬克宏退場後的中道真空，以「反EU、法國優先」路線吸納右傾選民。
- **組織面**：即使勒龐本人受阻，巴爾德拉作為備位人選已準備就緒，RN的候選人風險已被分散。

中道陣營的對策：拉加德的「待望論」反映出一種策略——以「歐洲代言人」形象對抗勒龐的反EU立場。拉加德在Les Echos訪談中明確表示「需要讓歐洲的聲音進入大選辯論」，暗示她將以親歐立場作為競選主軸。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 案例 | 對法國的適用性 |
|------|------|---------------|
| 中道聯合戰線（共和國陣線） | 2002年席哈克vs勒龐、2017年馬克宏vs勒龐 | 傳統有效，但2027年中道候選人缺乏魅力 |
| 左右大聯合政府 | 德國大聯合政府模式 | 法國政治文化不適應 |
| 技術官僚執政 | 義大利德拉吉模式 | 拉加德參選即此路線 |
| 憲法改革削弱總統權力 | — | 短期不可行 |

**市場風險**：若RN執政，其擴張財政政策（增加公共支出、減稅）將導致法國財政赤字擴大。法國國債殖利率可能飆升，歐元面臨貶值壓力。JBpress分析指出RN政權將引發「格下げリスク」（主權信用降級風險），類似2024年英國特拉斯減稅危機。

對用戶（東京、Softbank、關注匯率）的啟示：歐元貶值將推升日圓相對強勢，影響日本出口企業。法國政治風險溢價可能傳導至全球債券市場，間接影響日本利率政策。
