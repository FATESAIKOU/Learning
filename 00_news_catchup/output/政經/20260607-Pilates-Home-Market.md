# 27. 本格ピラティスマシンを自宅に。家庭用フィットネス市場の新規開拓狙う老舗企業 (原文)

**Source**: https://digiday.jp/glossy/ifit-bets-on-connected-pilates-with-10k-at-home-nordictrack-reformer-launch-plus-news/
**Author**: DIGIDAY [日本版] (翻訳: Lexy Lebsack, 藏西隆介)
**Date**: 2026/06/05
**Category**: 政治經濟

## 1. 這項產品解決什麼問題?

iFit 旗下 NordicTrack 於 2026/06 推出「Ultra 1 Reformer」,以 $5,000 (約 75 萬日圓) 切入家庭ピラティス市場,搭載 24 吋觸控螢幕 + 300 堂 on-demand 課程,目標成為「ピラティス界的 Peloton」。

| 規格 | 內容 |
|---|---|
| 售價 | $5,000 (約 ¥750,000) |
| 螢幕 | 24 吋可傾斜/旋轉觸控 |
| 課程 | 300 堂 on-demand ピラティス |
| 創新 | 推按式彈簧控制、Closed-Well 設計 |
| 對標 | 商用版 $10,000+ ($1.5M 日圓) |
| 上架 | 5 月預售, 6 月底出貨 |

## 2. 為什麼會發生?(背景)

### 2.1 Peloton 衰敗後的家庭健身後繼者爭奪戰

| 時間 | 事件 |
|---|---|
| 2020-2021 | Peloton 疫情紅利,股價 $160+ |
| 2022-2023 | Peloton 暴跌,庫存危機,裁員 |
| 2024 | Peloton 持續虧損,Apple Fitness+ 進入 |
| 2025 | iFit 收購 ReformRX (スマート Reformer 業者) |
| 2026 | NordicTrack Ultra 1 Reformer 推出 |

### 2.2 ピラティス市場的爆發性成長

| 數據 | 來源 |
|---|---|
| 2026 Q1 NYC 最熱門 boutique fitness | ClassPass |
| 2025 ClassPass 搜尋 2700 萬+ 次 | Playlist |
| 2025 ClassPass 予約 1500 萬+ 件 | Playlist |
| 旅行目的地 33% 預約為ピラティス | ClassPass (顯示ホスピタリティ潛力) |
| 後疫情「wellness」 | 健康、瑜珈、低強度訓練 |

### 2.3 Reformer 市場價格帶

| 區隔 | 價格 | 對象 |
|---|---|---|
| 商用版 (Pilates studio) | $10,000+ | スタジオ、專業用 |
| 家庭高階版 (本案 Ultra 1) | $5,000 | 重度愛好者 |
| 中價位家用 | $1,500-3,000 | 入門者 |
| 入門 Mat | $100-300 | Mat ピラティス,無機器 |

## 3. 產品機制如何運作?

### 3.1 Ultra 1 Reformer 設計

```text
硬體:
  24 吋觸控螢幕 (可傾斜/旋轉)
  + 推按式彈簧 (免手動更換)
  + Closed-Well 設計 (彈簧自動開合)
  + iFit App 整合 (進度追蹤)

內容:
  300 堂 on-demand 課程
  + 10 名世界級教練
  + 推測:live class 加入 (iFit 既有)

目標:
  重度家用戶 (studio 訂不到)
  + 旅行/商務客 (旅館配備)
  + 中高齡健康 (low-impact)
  + 集合住宅 (ホスピタリティ/集合住宅チャネル)
```

### 3.2 商業模式演進

| 階段 | 商業模式 |
|---|---|
| Reformer studio | 月費 $200-500 (課堂制) |
| Peloton (腳踏車) | 硬體 $1,500 + 月費 $44 |
| Tonal (壁掛健身) | 硬體 $3,000 + 月費 $50 |
| NordicTrack Ultra 1 (本案) | 硬體 $5,000 + 月費 (推測 $30-50) |

### 3.3 進入障礙與解方

| 障礙 | 解方 |
|---|---|
| 價格高 ($5,000) | 比商用 $10,000 便宜一半 |
| 空間需求 | Reformer 約 2.5m x 0.7m,可收折 |
| 課程選擇 | 300 堂 on-demand + iFit 既有課程 |
| 技術門檻 | 推按式彈簧、Closed-Well 簡化操作 |
| スタジオ替代 | 24/7 家庭使用,免預約 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **NordicTrack Ultra 1 (本案)** | 高階硬體 + on-demand 內容 | NordicTrack | 售價高,內容品質是關鍵 |
| **Peloton 訂閱模式** | 硬體補貼 + 月費 | Peloton | 訂戶流失,2022 後困境 |
| **Tonal 壁掛式** | AI 教練 + 力量訓練 | Tonal | 內容單一 |
| **Apple Fitness+** | iPhone/iPad/Apple TV + 訂閱 | Apple Fitness+ | 無専用硬體 |
| **YouTube/Instagram 直播** | 免費內容 + 創作者打賞 | Yoga with Adriene | 體驗碎片化 |
| **Studio 訂閱 (ClassPass)** | 多家 studio 月費 | ClassPass | studio 倒閉潮影響 |
| **Mirror (現 Lululemon)** | 壁掛螢幕 + 直播課 | Lululemon Mirror | 售價仍高 |
| **Adidas Training / Nike Training Club** | 免費 App + 周邊商品 | Nike, Adidas | 變現弱 |
| **AI Personal Trainer** | AI 教練 + camera 動作辨識 |推測: Tonal, Future, Whoop | 動作精準度仍待改進 |
| **ホスピタリティ B2B** | 高級飯店/公寓配備 | Equinox 飯店, Aman | B2B 銷售週期長 |

### 對使用者的意涵 (健身產業 + 健康經濟)

- **「ピラティス Peloton 化」** 反映 wellness 經濟 + 家庭健身的合流
- 對 Softbank/管理者:員工 wellness 福利可考慮引進ピラティス Reformer (B2B 通路)
- 對日本/台灣:ピラティス在亞洲仍屬成長期,Studio 擴張 + 家庭市場有雙重機會
- 推測:2026 下半年將有更多業者 (Lululemon, Equinox) 進入連網 Reformer 市場
