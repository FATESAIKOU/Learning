# 16. メルセデス・ベンツ GLA がフルモデルチェンジ まずはEVで来年ハイブリッド登場

**Source**: https://www.autocar.jp/post/1265713
**Author**: James Attwood（翻訳：林汰久也）
**Date**: 2026-07-31
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

Mercedes-Benz 第 3 代 **GLA** 大改款，解決**「compact SUV 產品在 EV 轉型期需同時支援純電與油電雙路線、且需對抗 Audi Q4 e-tron/Volvo EX40」的產品策略問題**。

| 問題面向 | 解法 |
|----------|------|
| 雙動力支援 | MMA 平台同時對應 EV 與內燃機 |
| EV 競爭力 | 800V 高壓 + 最大 657km 續航 + 320kW 快充 |
| 數位體驗 | MB.OS + Nvidia 晶片 + MBUX Super Screen |
| 產品定位 | 取代舊 EQA，對應 Audi Q4 e-tron/Volvo EX40 |

## 2. 這個問題為什麼會發生?(背景)

- Mercedes 電動化戰略從「全面電動」修正為「EV 與內燃機並行」，GLA 改款時序反映此轉向：**先推 EV（11 月），明年推 1.5L 油電**。
- compact SUV 級距競爭加劇：Audi Q4 e-tron、Volvo EX40、BMW iX1 等環伺。
- MMA 平台為 Mercedes 次世代 compact 平台，與 CLA、GLB 共用，藉規模分攤開發成本。
- 背景結構：歐洲 EV 需求增速放緩、充電基礎設施進度參差，使雙動力策略成必要對沖。

## 3. 這個技術/政策是如何解決該問題的?

GLA 產品結構：

```
第 3 代 GLA（MMA 平台）
├── 車體
│   ├── 全長 4565mm / 全寬 1873mm / 全高 1604mm / 軸距 2790mm
│   ├── 比前代長、車頂降 20mm（運動化）
│   └── 後座空間擴大、頭部空間增加、行李 410L（EV +107L frunk）
├── EV 動力（3 級距）
│   ├── GLA 200：224ps / 58kWh LFP 電池 / 後驅
│   ├── GLA 250+：272ps / 85kWh NMC / 最大 657km
│   └── GLA 350 4matic：354ps 雙馬達四驅
├── 充電/效率
│   ├── 800V 系統 → 最大 320kW 快充
│   └── 最高效 6.7km/kWh
├── 數位
│   ├── MB.OS 最新版
│   ├── Nvidia 晶片
│   ├── MBUX Super Screen（3 螢幕全寬，選配）
│   └── AI 語音控制 + 先進 ADAS
├── 油電（明年登場）
│   └── 1.5L 渦輪汽油 + 8AT + 30ps 電機 + 1.3kWh 電池
└── 價格（德國）
    ├── VAT 前 €40,800（約 765 萬日圓）
    └── VAT 後 €48,599.60（約 910 萬日圓）
```

關鍵策略選擇：**EV 先行、油電補位**——以 EV 衝刺環保法規/性能形象，油電顧及過渡期消費者與基礎設施不足市場。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 框架/方法 | 特色 | 與 GLA 對照 |
|-----------|------|------------|
| **MMA 共用平台** | CLA/GLA/GLB 共用降低開發成本 | 規模經濟典範 |
| **800V EV 架構** | Porsche/Hyundai/BMW Neue Klasse 採用 | GLA 採同代技術以對齊競爭 |
| **LFP vs NMC 電池分流** | 入門用 LFP、長續航用 NMC | GLA 200 LFP / 250+/350 NMC |
| **MB.OS 自研車用 OS** | 對抗 Android Automotive | 軟體定義車戰略核心 |
| **EV-first + HEV-follow 節奏** | 先 EV 搶法規/形象再補油電 | 雙動力時序策略 |
| **Audi Q9（同日發表）對照** | Audi Q9 首發柴油 MHEV、無 EV | 兩品牌大型 vs compact 的電動化節奏相反 |
| **BYD/中國 EV 雙動力** | 降價壓力下的雙策略 | 歐洲日系防禦中國進攻 |

對使用者的相關性：
- **技術擴展**：MB.OS + Nvidia 晶片 + AI 語音 + ADAS 即「軟體定義車」趨勢，與使用者學習的 AI/Spring+AI/MCP 等軟體技術在車用領域的延伸應用同源。
- **產業/政策**：日本工作視角下，Mercedes 在日本進口高級車市占第一，GLA 為主力銷售車型，大改款直接牽動日本高級車市場結構；EV/HEV 並行策略反映歐洲車廠在政策與市場間的務實平衡，與台灣/日本/AI 監管的亞太政策觀點可比對。
- **管理啟示**：「平台共用 + 雙動力 + 產品時序分流」是降低風險的產品組合設計，可類比應用於新創產品線規劃：共用核心模組、依市場成熟度分階上線不同變體，避免 all-in 單一技術路線的風險。
