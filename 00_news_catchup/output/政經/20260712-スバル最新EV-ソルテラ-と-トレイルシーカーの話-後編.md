# 19. スバル最新EV『ソルテラ』と『トレイルシーカー』の話（後編）言葉の響きよりも複雑な協業と共用

**Source**: https://www.autocar.jp/post/1257857
**Author**: 平井大介（AUTOCAR JAPAN編集長）
**Date**: 2026.07.12
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

Subaru的兩款最新EV——Solterra（SUV）和Trailseeker（旅行車）——共享Toyota的EV平台但定位截然不同。文章透過實駕比較，解決的問題是：同一平台如何透過調校差異化來滿足不同用戶需求？以及Subaru如何在Toyota主導的技術架構中保持品牌獨特性？

## 2. 這個問題為什麼會發生?(背景)

| 車型 | Solterra ET-HS | Trailseeker ET-SS |
|------|---------------|-------------------|
| 全長 | 4690mm | 4845mm (+155mm) |
| 輪胎 | 20吋 Bridgestone Alenza | 18吋 Yokohama Advan |
| 後馬達 | 與前馬達不同輸出 | 與前馬達相同 (227ps/268Nm) |
| 重量 | 2000kg | 2020kg |
| 價格 | 605萬日圓 | 594萬日圓 |
| 續航(實際) | 未提及 | 524km (目錄值690km) |

Trailseeker發表後2個月內受注1962台（月販目標250台的約4倍），顯示市場對Subaru風格EV的強勁需求。

## 3. 這個技術/政策是如何解決該問題的?

編輯長的實駕比較結論：

- **18吋Trailseeker**：乘坐感柔軟，但路面不平時「重量級EV特有的動作遲鈍感」較明顯
- **20吋Solterra**：乘坐感扎實，長距離移動更適合，動態輕快感優於重量差所能解釋的程度
- **最佳選擇推測**：20吋Trailseeker ET-HS（639萬日圓）可能是最佳平衡點

Subaru的差異化策略：外觀設計（Trailseeker的Outback風格側面）、輪胎選擇、馬達調校——在Toyota主導的硬體平台上，透過「軟體/調校層面」創造品牌差異。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 |
|------|------|
| 完全自主開發 | Subaru曾考慮但成本過高，最終選擇Toyota平台共用 |
| 平台共用+品牌調校 | 本案例模式，類似VW集團的MQB平台策略 |
| 僅做外觀差異化 | 成本最低但無法創造真正的駕駛體驗差異 |
| 專注燃油車/混合動力 | Subaru的水平對臥引擎+Symmetrical AWD是傳統強項 |

對用戶（技術背景、關注日本汽車產業）的啟示：Subaru-Toyota的EV平台共用是日本汽車產業「協業與競爭並存」的典型案例。類似於軟體開發中的「開源基礎+專有差異化」模式——共享底層降低成本，在上層創造獨特價值。
