# 08. New U.S. College Grads Now Have Higher Unemployment Than the Average Worker (原文)

**Source**: https://www.randalolson.com/2026/06/04/recent-grad-unemployment-flip/
**Author**: Dr. Randal S. Olson
**Date**: 2026/06/04
**Category**: 政治經濟

## 1. 這個現象解決什麼問題?

本文非政策解法,而是診斷報告:2026 年起,美國 22-25 歲新鮮大學畢業生的失業率(5.6%)**反高於**整體勞動人口(4.2%),差距為歷史最大;同時 41% 在職新鮮人是「學歷過剩 (underemployed)」。

| 問題面向 | 具體症狀 |
|---|---|
| 個體經濟 | 大學文憑的入職溢價 (college premium) 對 Z 世代縮水 |
| 勞動市場 | 入門職 (entry-level) 整體縮減,新血進入職場管道被切斷 |
| 教育 ROI | 大學學費仍持續上漲,但求職回收期拉長,引發學貸違約風險 |
| 產業升級 | AI + 遠端工作同時壓縮 white-collar junior 職缺 |

## 2. 這個問題為什麼會發生?(背景)

### 時間軸

| 年份 | 事件 |
|---|---|
| ~2000 | 年輕學士就業優勢開始緩慢侵蝕 (Cleveland Fed) |
| 2010 | 金融海嘯期:文憑價值最高峰(學士失業 7% vs 全體 10%) |
| 2019-02 | 差距首次反轉,文憑不再有溢價 |
| 2020-2021 | COVID 衝擊,學士與全體失業同步飆升,差距未惡化 |
| 2022-末 | 生成式 AI 爆發 |
| 2024-2025 | 22-25 歲 AI 暴露度高的職業 employment 下降 ~16% |
| 2026-04 | 學士失業 5.6% / 全體 4.2% (BLS 數據) |

> 關鍵觀察:**反轉早於 AI、早於 COVID**。結構性因素為主,AI 為加速器。

### 三大結構性原因

| 原因 | 機制 | 證據 |
|---|---|---|
| Credential inflation (學歷貶值) | 雇主把「學士」當篩選門檻而非能力訊號,所有人擠破頭 | Cleveland Fed 2000 以來趨勢 |
| 遠端工作排除新人 | 遠端環境難以提供 on-the-job mentorship,雇主偏好 hire senior | NY Fed 估算貢獻 64% |
| AI 取代 routine junior tasks | 22-25 歲 AI-exposed 工作 employment -16% | Stanford 研究 |

## 3. 為何這些因素合流形成「學歷溢價反轉」?

### 3.1 訊號理論失敗 (Signaling failure)

```text
雇主原本解讀:
  學位 = 智識 / 紀律 / 抗壓 → 願意 hire & train

現在解讀:
  學位 = 已通貨膨脹的最低門檻 → 只用來過濾,不願意 train
  + 遠端無法 on-the-job learning
  + AI 可代勞 L1 routine tasks
  → 結論: hire senior 比較划算
```

### 3.2 CS 學位特別慘況

- CS 學位 5 年內翻倍(2018-2023),但 AI 自動化 coding 助理吃掉 L1 缺
- 推測:同樣壓力將擴散到 junior legal/paralegal、junior financial analyst、junior consulting

### 3.3 結構性 vs 循環性

| 層級 | 證據 |
|---|---|
| 全體學士失業 | 2.8% (BLS 2026/04) < 高中學歷失業 → 學位**本身**仍值錢 |
| 新鮮學士失業 | 5.6% > 全體 → 「on-ramp」斷裂 |
| 結論 | **不是學位無用,是 entry-level 職缺消失** |

> 關鍵洞察:這是 **on-ramp problem, not degree problem**——「門票還有效,但剪票口的旋轉門壞了」。

## 4. 是否存在解決類似問題的其他框架 / 思考方式?

| 框架 | 機制 | 應用層級 | 對使用者的效果 |
|---|---|---|---|
| **Apprenticeship model (學徒制)** | 雇主投資 2-3 年 on-the-job 培訓,搭配學校 | 國家政策 (德國、瑞士模式) | 企業需承擔短期人力成本 |
| **Skills-based hiring** | 拋棄學位門檻,改用 portfolio / 證照 | HR 政策 | 釋放非傳統路徑人才 |
| **AI-augmented junior roles** | 重設計 L1 職缺為「AI 監督 + 例外處理」 | 公司內部 | 讓 AI 強化而非取代新人 |
| **強制 mentorship / 見習期** | 對 senior 員工加 mentorship KPI | HR 政策 | 縮短新人 productive ramp |
| **回流教育 (Bootcamp + 企業合作)** | 12-24 週密集訓練取代 4 年學位 | 教育端 | 加速特定技能,降低學貸 |
| **推測:工會/集體協議** | 限制企業用 AI 取代 L1,要求比例配置 | 產業層級 | 推測:歐洲可能採行 |

### 對用戶的即時意涵 (RoR + React + GCP)

- 招募策略:junior 軟體工程招募**顯著變難**;senior 職缺仍熱門
- 團隊設計:可考慮「senior 帶 junior 學徒」模型,把 mentorship 寫入 KPI
- 管理者:在轉任前先理解「entry-level 管道斷裂」對 diversity / talent pipeline 的中長期衝擊
- 地緣政治:學歷貶值 + AI 衝擊 + 學貸違約,可能成為 2026-2028 美國大選的青年政策議題
