## 2. 為什麼會發生?(背景)

### 2.1 日本廣告業的「規劃派 vs 即興派」光譜

| 光譜端 | 代表人物/風格 |

### 2.3 「計画しない人」能成功的結構性原因

| 條件 | 機制 |
|---|---|
| 機運 (luck) | 隨機事件撞上準備好的人 |
| 復元力 (resilience) | 失敗→學習→再挑戰的循環 |
| 場域多樣性 | 多元經歷反而成為素材 |
| 人脈偶然性 | バー常客、Twitter(X) 粉絲、廣告業前輩 |
| 日本僱用慣行 | 推測:終身僱用制下「安定枠」,才有「不計画」的本錢 |

## 3. 「計画しない」哲學如何運作?

### 3.1 佐野式「Lucker-driven 人生」框架

| 步驟 | 行動 |
|---|---|
| 1. 失敗を許容 | 失敗は帳尻合わせの材料 |
| 2. 多領域を渡り歩く | バー、カラオケ、ゲーム、廣告で「場」を重ねる |
| 3. 偶然を保存 | Twitter つぶやきが「履歴書」になる |
| 4. 偶然を仕事に変換 | 受賞・転局試験→CM Planner |
| 5. 結果に納得 | 「ラッキーでよかった」と受け入れる |

### 3.2 廣告人としての「即興力」

| 能力 | 展現場景 |
|---|---|
| 觀察力 | 商店街ナンパ、藥妝店應對 |
| 共感力 | 「客の欲しい」を即座に言語化 |
| 編集力 | バー経営失敗談→廣告コピーへ変換 |
| 社交力 | ホスト時代の「即興トーク」→ CM ナレーション |
| 反省力 | E案連発、上司から「お前は空手やってんのか」→ 學習 |

### 3.3 計画 vs 帳尻合わせ 對比

| 軸 | 計画型 | 帳尻合わせ型 |
|---|---|---|
| 時間觀 | 線性、未來導向 | 循環、現在導向 |
| 風險 | 規劃失敗 = 大失敗 | 每次都「差不多對」 |
| 心理 | 焦慮於「未達標」 | 滿足於「意外收穫」 |
| 適合 | 製造業、會計、軍隊 | 創意、創業、社交 |
| 終點 | KPI 達成 | 故事性、意義構築 |

## 4. 解決類似問題的其他思考方式

| 框架 | 主張 | 應用 | 限制 |
|---|---|---|---|
| **計画型 (本案對比)** | 5年/10年規劃、PDCA | 企業管理、專案 | 不適合變動環境 |
| **帳尻合わせ型 (本案)** | 走一步算一步,接住偶然 | 創意/創業 | 需要運氣+韌性 |
| **エフェクチュエーション (Sarasvathy)** | 「可承受損失內實驗」、「意外當資產」 | 創業研究 | 學術框架,非大眾語言 |
| **「IKIGAI」型** | 熱情+擅長+世界需要+報酬交會 | 日本職涯設計 | 過於理想化 |
| **OODA Loop (軍事決策)** | Observe→Orient→Decide→Act 快速循環 | 動盪環境 | 需高素質個人 |
| **Lean Startup** | Build-Measure-Learn 最小可行循環 | 新創 | 與即興部分重疊 |
| **「全力疾走」型** | 拼命努力,機會自然來 | 推測:日本昭和式 | 與心理健康衝突 |
| **「ポートフォリオ型職涯」** | 同時經營多軌身分 | 現代斜槓 | 注意力分散 |

### 對使用者的意涵 (管理者 + 創意)

- **即興力** 對管理者同樣重要:計畫常因市場變動而失效,須有 OODA 能力
- 對 Softbank AxrossRecipe:工程師招募時,「非典型背景」(酒吧老闆、遊戲商)反而是創意資產
- 對台灣/日本 IT 業:終身僱用制變動下,「不計画」哲學為 Z 世代職涯設計提供新範式
- 管理者:理解員工「不計画」並非缺乏紀律,而是另一種策略

---

**對台灣/日本廣告業的啟示**:
- 創意產業的「計画 vs 即興」辯論持續中,佐野案例為「即興派」提供代言人
- 推測:日本廣告業 AI 化,「即興力」反而成為人類的最後堡壘
- 對管理者:招募創意人才時,「多元失敗經驗」是優點而非缺點
- 對台灣:從佐野經歷反思台灣廣告業的「責任制 + 提案文化」是否扼殺即興力
