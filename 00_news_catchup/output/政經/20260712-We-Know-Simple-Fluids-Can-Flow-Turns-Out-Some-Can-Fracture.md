# 09. We Know Simple Fluids Can Flow. Turns Out, Some Can Fracture.

**Source**: https://www.quantamagazine.org/we-know-simple-fluids-can-flow-turns-out-some-can-fracture-20260710/
**Author**: Rohini Subrahmanyam
**Date**: July 10, 2026
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

Drexel大學的研究團隊發現：非彈性的簡單流體（simple fluid）在足夠的拉伸應力下會像固體一樣脆性斷裂（brittle fracture），而非如傳統認知那樣只會流動或空化（cavitation）。這顛覆了流體力學的既有理論——過去認為只有具備彈性的複雜流體（如聚合物熔體）才會斷裂。

## 2. 這個問題為什麼會發生?(背景)

| 舊理論 | 新發現 |
|--------|--------|
| 只有彈性流體（viscoelastic）會斷裂 | 非彈性簡單流體也會脆性斷裂 |
| 斷裂與彈性有關 | 斷裂與分子間的「內聚能」（cohesive energy）有關 |
| 簡單流體只能透過空化（氣泡）釋放應力 | 足夠多的氣泡快速形成時，可像玻璃裂紋一樣傳播 |

研究契機：博士生 Thamires Lima 在與Exxon Mobil合作項目中，用拉伸流變儀測試碳氫混合物時聽到「啪」的脆響——最初以為是機器故障，反覆測試後確認是流體本身斷裂。

## 3. 這個技術/政策是如何解決該問題的?

研究團隊使用高速攝影機觀察斷裂過程，發現：

- **裂紋傳播速度**：簡單流體中裂紋速度達500-1500 m/s，遠快於複雜流體中的0.07 m/s。因為簡單流體中沒有長分子鏈吸收能量來減緩裂紋。
- **臨界應力**：不同流體（簡單和複雜）都在約2 MPa的臨界應力下斷裂，暗示存在普適的斷裂準則。
- **裂紋形狀**：複雜流體中呈喇叭狀，簡單流體中呈玻璃狀裂紋。

理論推測：斷裂與液體的「內聚能」有關，而非彈性。這呼應了1990年代Daniel D. Joseph的預測——任何液體在足夠撕裂應力下都會斷裂。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 應用領域 | 潛在影響 |
|----------|----------|
| 纖維紡絲（spinning fibers） | 理解斷裂機制可優化工業紡絲過程 |
| 噴墨印刷 | 控制墨水滴的斷裂行為 |
| 腦損傷防護 | 腦脊液在衝擊下的斷裂行為 |
| 軟體機器人 | 液體驅動器的失效模式 |
| 石油開採 | 原油在多孔介質中的斷裂行為 |

對用戶（技術背景）的啟示：此發現屬於基礎科學突破，短期無直接商業應用。但研究方法（高速攝影+流變儀+理論建模）展示了「意外發現→系統驗證→理論重構」的科學方法論，對技術研發管理有參考價值。
