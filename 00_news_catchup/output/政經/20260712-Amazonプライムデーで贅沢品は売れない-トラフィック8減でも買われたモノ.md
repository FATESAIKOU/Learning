# 12. Amazonプライムデー で贅沢品は売れない？トラフィック8％減でも買われたモノ

**Source**: https://digiday.jp/modern-retail/prime-day-results-suggest-shoppers-are-saving-splurges-for-black-friday/
**Author**: Allison Smith（翻訳・編集：藏西隆介）
**Date**: 2026年7月
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

2026年Amazon Prime Day（6月23-26日，首次6月舉辦）的消費行為數據揭示：消費者正在從「衝動購買高價品」轉向「計劃性囤積日用品」。這反映的不是Prime Day本身的問題，而是通膨環境下消費者支出模式的結構性轉變。

## 2. 這個問題為什麼會發生?(背景)

| 指標 | 數據 | 含義 |
|------|------|------|
| 總線上支出 | 264億美元（歷史新高） | 參與人數增加 |
| 世帶平均支出 | $143.45（較2025年$156.37下降9%） | 單筆消費減少 |
| 家電購買比例 | 僅14% | 高價品需求萎縮 |
| 汽油價格 | 約$4/加侖 | 通膨壓力持續 |
| 流量 | 年減8% | 瀏覽減少 |
| 轉換率 | 年增19% | 購買意圖更明確 |
| 總訂單數 | 年增10% | 購買效率提升 |
| 回頭客佔比 | 56%（較去年降15%） | 新客增加但忠誠度分散 |

## 3. 這個技術/政策是如何解決該問題的?

消費者的自適應策略：

- **囤積必需品**：蛋白粉、垃圾袋、貓零食等消耗品銷量領先。AquaSonic的替換刷頭銷量年增2-4倍，超過新電動牙刷。
- **計劃性購買**：消費者帶著購物清單來，而非隨意瀏覽。流量降8%但轉換率升19%。
- **跨平台比價**：4天活動期間，消費者在Amazon、Walmart、Target、TikTok Shop之間比價，衝動購買難度增加。

品牌端的困境：約100品牌的支援公司Incrementum Digital報告客戶銷售較前30天增66%，但低於2025年的81%。部分小品牌因Amazon手續費上漲而退出Prime Day。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 |
|------|------|
| 訂閱制（Subscribe & Save） | Amazon已有的定期配送折扣，適合消耗品 |
| 自有品牌低價替代 | Amazon Basics等自有品牌在通膨期更具競爭力 |
| 年末集中消費 | 消費者將大額購買推遲至Black Friday/Cyber Monday |
| 社交商務 | TikTok Shop等新渠道分流 |

對用戶（東京生活、關注消費趨勢）的啟示：日本同樣面臨日圓貶值下的輸入性通膨。Prime Day的「必需品囤積、高價品推遲」模式可能在日本重現。對Softbank投資的零售/電商相關企業，此趨勢影響定價和促銷策略。
