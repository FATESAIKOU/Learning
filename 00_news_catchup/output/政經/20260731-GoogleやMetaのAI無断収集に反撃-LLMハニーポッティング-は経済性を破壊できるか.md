# 13. GoogleやMetaのAI無断収集に反撃。 LLMハニーポッティング は経済性を破壊できるか

**Source**: https://digiday.jp/publishers/wtf-is-llm-honeypotting/
**Author**: Jessica Davies（翻訳：英じゅんこ、編集：京岡栄作）
**Date**: 2026-07
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

**LLM Honeypotting（LLM 蜜罐誘捕）** 解決**「AI 業者未經授權大規模爬取網站內容，且內容方缺乏有效反制手段」的問題**。

| 問題面向 | 現況 | 蜜罐目標 |
|----------|------|----------|
| 爬蟲成本 | OpenAI/Google/Meta 等限界成本近乎零 | 每筆請求附加金錢/計算成本 |
| 內容價值 | 高品質內容被免費榨取 | 灌入無意義內容污染模型品質 |
| 反制手段 | robots.txt 形同虛設、IP 封鎖易繞過 | 經濟性破壞取代單純遮斷 |

核心政策目標：**讓無授權爬取的「割に合わない（不划算）」，從根破壞白嫖商業模式**。

## 2. 這個問題為什麼會發生?(背景)

- LLM 訓練與 RAG 系統對網路內容需求暴增，第三方爬蟲活躍化，publisher 與電商網站被大量無斷スクレイピング。
- 傳統反制（robots.txt、IP block、CAPTCHA）效果有限，且繞過門檻低；IP 封鎖又會誤傷正常用戶。
- Fastly 共同創辦人 Simon Wistow 指出，欺瞞戰術（deception）在資安界行之有年，核心思想是**「若惡用成本 > 惡用利益，商業模式崩潰」**。
- 背景張力：內容方陷入「打手心不甘、不打被榨乾」困境，蜜罐被部分 publisher 視為「最後的あがき（最後掙扎）」。

## 3. 這個技術/政策是如何解決該問題的?

蜜罐機制分層：

```
LLM Honeypotting 手法
├── A. 計算成本攻擊
│   ├── PoW（Proof of Work）：對 bot 強加計算題
│   └── 微妙延遲：人類無感、bot 累積耗時
├── B. 無限迷宮
│   └── 生成貌似真實實則無意義的頁面，無限供 bot 瀏覽
│       （例：bot 5 天後已瀏覽 2000 萬頁）
├── C. 模型汙染
│   └── 餵入統計上看似合理實則無意義資訊
│       → 誘發 hallucination、劣化回答品質
│       → 打擊「免費搭便車」系統信用
└── D. 對象
    └── 不只惡意攻擊者，連「只是煩人的 bot」一併視為攻擊者
```

關鍵設計差異：**不是「遮斷」而是「讓對方付錢」**。目標不在一次消滅，而在讓長尾爬蟲商業模型破產。大型網站（頁面配送成本高、守護利益大）採用門檻低，尤其搭配 Fastly/Cloudflare/Akamai 邊緣平台時運作成本下降。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 框架/方法 | 特色 | 與蜜罐對照 |
|-----------|------|------------|
| **robots.txt + 法律授權** | 礼貌性協議，缺乏強制力 | 蜜罐是「非合作博弈」替代方案 |
| **IP 速率限制 / WAF** | 阻斷異常流量 | 易繞過、誤傷正常用戶；蜜罐改採「放行但加價」 |
| **CAPTCHA / 行為指紋** | 區分人機 | 對 stealth crawler 失效（蜜罐也部分失效） |
| **內容水印 / 追蹤（如 C2PA）** | 事後舉證侵權 | 事後救濟 vs 蜜罐事前嚇阻 |
| **授權 marketplace（如 OpenAI 授權 Reddit/News Corp）** | 合法付費取得 | 正面方案；蜜罐是反面施壓促成談判 |
| **PoW 反垃圾（如 Hashcash 反 spam）** | 提高對方運算成本 | 蜜罐 A 手法即此古老技術的 LLM 版 |
| **Data Poisoning（如 Nightshade、Glaze）** | 對生成模型投毒 | 藝術家反 AI 工具同源思路 |

對使用者的相關性：
- **技術面**：蜜罐中的 PoW/無限迷宮是 web 防禦設計模式，與 K8s/GKE 邊緣部署、Nomad 工作負載調度有工程關聯。
- **政策面**：日本工作、台灣人視角下，AI 訓練資料治理是亞太 AI 監管核心議題之一，蜜罐代表「私力救濟」路徑，與政府立法形成對照。
- **管理面**：對即將轉管理者的使用者，此案例示範「經濟性破壞 vs 規則遵守」的策略選擇框架——當對方不守規則時，改變對方成本結構比說服更有效。
