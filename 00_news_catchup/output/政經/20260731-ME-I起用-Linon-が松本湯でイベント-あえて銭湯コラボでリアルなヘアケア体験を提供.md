# 12. ME:I起用 Linon が松本湯でイベント あえて銭湯コラボでリアルなヘアケア体験を提供

**Source**: https://www.advertimes.com/20260731/article552426/
**Author**: 宣伝会議
**Date**: 2026-07-31
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

SOLIA 旗下護髮品牌 **Linon** 解決**「數位護髮行銷缺乏真實體感場景」的問題**，透過與東京東中野錢湯「松本湯」異業合作，將品牌世界觀植入日常公共空間。

| 問題面向 | 傳統做法 | Linon 解法 |
|----------|----------|------------|
| 體驗場景 | 店頭/沙龍/數位廣告 | 錢湯（素の自分に戻れる場所） |
| 訊息一致性 | 廣告與產品體驗分離 | 『Update ME』概念貫穿樂曲→SNS→實地體驗 |
| 觸及方式 | 付費媒體曝光 | 日常空間 + 網紅 + 互動裝置 |

核心問題：**如何讓消費者在「最真實、最放鬆的場所」接觸品牌，而非在廣告框架內被動接收**。

## 2. 這個問題為什麼會發生?(背景)

- Linon 自 2026 年 4 月起起用 K-pop 女團 **ME:I** 為品牌大使，推出合作曲『Update ME』、概念影片、SNS 投稿、合作包裝。
- 品牌核心訊息為「ちょうどいいかわいい自分になれる」（剛剛好的可愛自我），需要一個能讓消費者「回到素顏」的實體場景承載。
- 錢湯在日本文化中具備「日常/公共/裸足真實」三重屬性，與化妝/護髮品牌的「妝前/素顏」敘事高度契合。
- 背景趨勢：日本品牌近年盛行「非典型場所體驗行銷」（車站/神社/錢湯/防空壕），以對抗數位廣告疲勞。

## 3. 這個技術/政策是如何解決該問題的?

活動設計（8/6-8/19，松本湯）：

```
活動結構
├── 概念：「お風呂が、自分をアップデートする時間になる」
├── 體驗點
│   ├── 浴室/脫衣所：產品實際試用
│   ├── 休憩區：關鍵視覺展示
│   ├── 扭蛋機
│   └── 拍攝打卡點
├── 一致性軸
│   └── 『Update ME』串接：樂曲 → SNS → 包裝 → 現地體驗
└── 品牌邏輯
    └── 錢湯＝素の自分に戻れる → 在該處體驗 Linon = ちょうどいいかわいい自分
```

關鍵設計：不是「在錢湯打廣告」，而是「讓錢湯本身成為品牌體驗的舞台」，產品試用嵌在日常浴流程中而非外加展示。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 框架/方法 | 特色 | 對照本件 |
|-----------|------|----------|
| **體驗行銷（Experience Marketing, Pine & Gilmore）** | 以顧客感官參與為核心創造記憶 | 錢湯沉浸式體驗即此框架極致版 |
| **場所品牌化（Placemaking）** | 將公共空間賦予品牌敘事 | 錢湯改造為品牌場域 |
| **O2O（線上到線下）閉環** | 數位話題導流到實體體驗 | ME:I 樂曲導流到松本湯 |
| **Brand Worlds（品牌宇宙）** | 跨載具一致世界觀（樂曲/包裝/實體） | 『Update ME』軸貫穿 |
| **Pop-up in Heritage Space** | 在歷史/文化空間做快閃 | 錢湯作為 heritage 場域 |
| **Pull Marketing vs Push** | 不強推而是在自然場景被發現 | 錢湯為顧客既有行為路徑 |

對使用者而言，本件示範**「非典型場域 + 跨載具敘事一致 + 既有行為路徑嵌入」**的小預算品牌突圍模式：對孵化新創團隊以有限預算創造差異化體驗具參考價值，亦可作為管理者評估「體驗型 vs 廣告型」行銷投資報酬的對照案例。
