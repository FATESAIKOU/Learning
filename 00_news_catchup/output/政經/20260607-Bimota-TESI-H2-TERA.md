## 1. 這款產品解決什麼問題?

Kawasaki Motors Japan 於 2026/06/05 宣布,以日本總代理商身份引進義大利高級手工摩托車品牌 Bimota 的「TESI H2 TERA」,售價 ¥6,380,000(本體 ¥5,800,000 + 消費稅 ¥580,000),2026/07/01 上市。本車搭載 Kawasaki Z H2 スーパーチャージャー引擎,結合 Bimota 著名的 TESI センターハブステアリング系統。

| 規格 | 內容 |
|---|---|
| 售價 | ¥6,380,000 (含稅) |
| 引擎 | Kawasaki Z H2 スーパーチャージャー 998cc 並列 4 気筒 |
| 變速箱 | (推測)6 速 |
| 操向 | TERA ステアリング (升級版センターハブ) |
| 重量配分 | 52.5 : 47.5 (前:後) |
| 製造 | 義大利 Rimini,工匠手作 |
| 數量 | 少量生產 |

## 2. 為什麼會發生?(背景)

### 2.1 Bimota 的歷史定位

| 時期 | 演進 |
|---|---|
| 1972 | 義大利 Rimini 創業 |
| 1990s | 與 Ducati/Suzuki 等多家引擎合作 |
| 2019 | TESI H2 (與 Kawasaki 首次合作) |
| 2022 | Kawasaki 收購 49% 股權,深化合作 |
| 2025 | TESI H2 TERA 概念發表 |
| 2026/07 | 日本上市 |

### 2.2 TESI 系統的技術原理

```text
傳統摩托車:
  車把手 → 前フォーク → 前輪 (直接連動)
  + 煞車時「dive」(前傾)、「squat」(加速後沉)

TESI センターハブステアリング:
  車把手 → ステアリングダンパー → センターハブ → ドラッグリンク → 前輪
  + ステアリング軸が車體中央
  + 前フォークが「anti-dive / anti-squat」特性
  + 煞車、加速時車體更穩定
  + 路面衝擊不會直接傳到把手 (舒適性)
```

### 2.3 為何 Kawasaki + Bimota 合作?

| 因素 | 機制 |
|---|---|
| Bimota 弱點 | 引擎研發能力不足,需依賴大廠 |
| Kawasaki 需求 | 提升品牌形象,進入超高端市場 |
| 法規優勢 | Bimota 少量生產可避開 Euro 5+ 等大規模法規成本 |
| 商業模式 | 推測:Bimota 負責車體設計,Kawasaki 提供引擎 + 電子控制 |
| 限量稀缺性 | 工匠手作 → 收藏價值 + 高定價 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **Bimota + Kawasaki OEM 合作 (本案)** | 引擎共用 + 車架差異化 | TESI H2 TERA | 法規責任歸屬複雜 |
| **Ducati 自主** | 自有引擎 + 自有車架 | Superleggera | 研發成本高 |
| **MV Agusta 限量** | 義大利工藝 + 中量引擎 | Brutale 1000 | 財務不穩定 |
| **Honda 內製** | 自有引擎 + 電子控制 | RC213V-S | 量產為主 |
| **車廠顧問 (Triumph/British)** | 復古 + 現代技術 | Thruxton RS | 銷量天花板 |
| **賽道限定版** | 賽道化規格 + 少量認證 | Yamaha R1M | 需賽道使用 |
| **客製化訂製** | 客戶主導設計 | 推測:Confederate, Dodge Tomahawk | 單台售價驚人 |
| **Hub-center steering 競爭** | 同技術不同實作 | Yamaha 03GEN-f, Yamaha GTS1000 (1993) | 量產車型少 |

### 對使用者的意涵 (高端機械 + OEM 合作)

- **OEM 合作** 是日本機車/汽車業進入超高端市場的常見路徑
- 對 Softbank/管理者:理解「技術內製 vs 外部合作」的策略選擇
- 對日本/台灣:Bimota 模式可應用於「台灣品牌 + 日本引擎」合作
- 推測:限量車的商業邏輯在於「品牌高度」>「銷量」,非營收主要來源

---

**對日本/台灣的具體啟示**:
- 日本機車業 OEM 合作 (Bimota + Kawasaki, Husqvarna + KTM) 是產業趨勢
- 台灣可借鏡:本土機車品牌 (Kymco, SYM) 與日系引擎廠合作,進軍高階市場
- 對管理者:理解「少量多樣 + 高單價」與「大量低價」是兩種截然不同的策略
- 機械工程的「中長期投資」(TESI 系統研發 30+ 年) 與 IT 業的技術累積邏輯類似
