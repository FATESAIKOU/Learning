# 13. Webの全商品をライブで売る。新興コマースアプリが描くネット通販の未來

**Source**: https://digiday.jp/glossy/fashion-is-now-the-largest-category-on-whatnot-as-brands-flock-to-the-platform/
**Author**: Danny Parisi（翻訳・編集：藏西隆介）
**Date**: 2026/06
**Category**: 政治經濟

## 1. この技術/政策解決什麼問題?

従來のネット通販（EC）が抱える3つの構造的課題を、ライブショッピングが解決する:

| 従來ECの課題 | ライブショッピングの解決策 |
|-------------|------------------------|
| 商品との距離感（寫真・テキストだけでは伝わらない） | リアルタイムのデモンストレーションと対話で商品の実體感を伝達 |
| 低いリピート率（検索→購入→離脫） | コミュニティ形成による高いロイヤルティ（リピート率は標準ECの最大10倍） |
| ブランドと消費者の斷絶 | 創業者・出品者が直接ライブ配信し、パーソナルな関係を構築 |

ワットノット（Whatnot）は「インターネット上で売られているものはすべて、ライブで売ることができるし、売られるべき」というビジョンのもと、ライブオークション形式でECのパラダイムシフトを推進している。

## 2. この問題為什麼會發生?(背景)

**ワットノットの成長軌跡**:
- 當初はコレクター向けアイテム・スポーツトレーディングカードからスタート
- 2025年後半に2億2500萬ドルの資金調達を実施、企業価値は110億ドル（約1兆6500億円）超に
- この1年間で2000萬人の購入者がプラットフォームに參加
- 2026年4月、Apple App Storeでダウンロード數2位のショッピングアプリに（Amazon・eBayを上回る）

**ファッションカテゴリーの臺頭**:
- ファッションの売上はスポーツカテゴリーより一桁大きい規模に成長
- 月間1200萬件超のファッション注文が成立
- 高級バッグ（シャネル等）のライブオークションが成長をけん引
- 日本やフランスからのヴィンテージ品・限定品の越境取引も活発

**市場規模**:
- 米國のライブショッピング売上は2026年に500億ドル（約7兆5000億円）に到達（eMarketer調査）
- 競爭プラットフォームのTiltも2600萬ドルの資金調達を完了、ユーザーは1日1時間超をアプリ內で消費

## 3. この技術/政策是如何解決該問題的?

**ワットノットのビジネスモデル構造**:

```
[出品者] 個人セラー / ブランド公式 / 創業者
    ↓ ライブ配信で商品説明・オークション開催
[プラットフォーム] Whatnot
    ├── Shopify API連攜（ブランドが簡単に出品開始可能）
    ├── メタデータ登録ツール（商品情報の自動補完）
    └── Entrupy公式鑑定パートナー（高級品の真贋保證）
    ↓
[購入者] リアルタイム入札・チャット參加・コミュニティ形成
```

**ブランド直接販売の加速**:
- Dolls Kill（ファッション）、Invicta（時計）、Callaway（ゴルフ）が公式出店
- 各ブランド數萬人のフォロワーを獲得
- 創業者自身がライブ配信に出演する「創業者主導型ブランド」が特に成功

**データが示す重要なインサイト**:
- プラットフォーム上の商品の90%は一般的な商品情報しか持たない
- しかし初回購入の90%は詳細な商品情報を備えた商品から発生
- → ブランド・新規顧客にとってメタデータの充実がコンバージョンの鍵

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| プラットフォーム | アプローチ | 強み | 弱み |
|-----------------|-----------|------|------|
| Whatnot | ライブオークション特化 | エンタメ性×購買の融合、コミュニティ形成力 | 日本未展開（現狀） |
| TikTok Shop | ショート動畫×ライブコマース | 圧倒的なユーザー基盤とアルゴリズム | エンタメ性が強く購買意図が希薄なケースも |
| Amazon Live | 既存ECのライブ拡張 | 圧倒的な商品數と物流インフラ | ライブコマースとしての沒入感は低い |
| Tilt | ライブショッピング特化（Whatnot競爭） | ユーザー滯在時間が長い（1日1時間超） | 規模ではWhatnotに劣後 |
| Instagram Live Shopping | SNSネイティブのライブ販売 | 既存フォロワー基盤を活用 | ライブコマース専用のUXではない |

**ユーザー（Softbank AxrossRecipe）への示唆**:
- ECプラットフォームの進化は、GCP/GKE上でのマイクロサービス開発に攜わるチームにとって、リアルタイム配信・オークションシステム・決済処理といった技術要件の參考になる
- Shopify API連攜のような「既存プラットフォームとの相互運用性」は、B2Bプロダクト開発においても重要な設計思想
- ライブコマースのリピート率が標準ECの最大10倍というデータは、ユーザー體験設計における「リアルタイム性」と「コミュニティ」の価値を示している
