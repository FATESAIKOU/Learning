# 8. 東急エージェンシー、三菱食品、unerry、OOH広告の購買効果を可視化するサービスを提供開始

**Source**: https://markezine.jp/news/detail/77055
**Author**: MarkeZine編集部
**Date**: 2026-06-26
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

傳統 OOH（Out-of-Home）戶外廣告的最大痛點：**投資對效果（ROI）難以量化**。相較於數位廣告可精準追蹤點擊與轉換，車站看板、車廂廣告、街頭ビジョン等 OOH 媒體的「廣告接觸→實際購買」因果鏈長期缺乏數據支撐。本服務透過ビーコンデータ × ID-POS × 位置情報的三方數據連攜，首次實現 OOH 廣告購買效果的定量評估。

## 2. 這個問題為什麼會發生?(背景)

| 技術瓶頸 | 說明 |
|----------|------|
| 接觸測量 | OOH 廣告無法像數位廣告般追蹤「誰看到了廣告」 |
| 購買歸因 | 即使知道有人看到廣告，也無法連結到實際購買行為 |
| 數據孤島 | 廣告曝光數據（媒體社）與購買數據（小売/メーカー）分屬不同系統 |
| 隱私限制 | 個人追蹤需符合隱私法規，不能簡單串聯個人 ID |

三社分工：
- **東急エージェンシー**：提供「Phygital Syndicate」ビーコンデータ（東急線沿線的數位/物理融合基礎）
- **三菱食品**：提供購買分析數據（ID-POS）
- **unerry**：提供「Beacon Bank for OOH」效果測定服務（位置情報分析）

## 3. 這個技術/政策是如何解決該問題的?

1. **三層數據連攜**：ビーコンデータ（廣告接觸） + 位置情報（unerry） + ID-POS（購買）→ 在同一隱私安全環境下交叉分析
2. **隱私保護設計**：取り扱うデータに個人情報は含まれず、セキュアな環境で連携
3. **實證結果**：

| 媒體類型 | 購買率提升 |
|----------|-----------|
| 渋谷大型ビジョン 2 媒體複合接觸 | 約 1.9 倍（vs 非接觸者） |
| 車両広告 | 約 2.1 倍（vs 非接觸者） |

4. **統一評估尺度**：不同媒體類型（駅/街/車両）可用同一指標比較，解決了 OOH 業界長期缺乏共通 KPI 的問題

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 代表 | 特徵 | 限制 |
|------|------|------|------|
| アンケート調査 | 傳統手法 | 事後問卷回憶廣告接觸 | 回憶偏差大，樣本小 |
| 手機 GPS + 購買數據 | 本服務 | ビーコン + ID-POS + 位置情報 | 限於特定エリア（東急沿線） |
| DOOH アドベリフィケーション | LIVE BOARD × OOH TRACE | 數位看板的曝光驗證 | 僅驗證曝光，不連結購買 |
| AI カメラ分析 | 各社開発中 | 攝影機偵測觀看人數/停留時間 | 隱私爭議，無法連結購買 |
| 統合分析平台 | ジーニー「Lumora」 | DOOH + Web + CTV 一括配信・統合分析 | 跨渠道但 OOH 購買歸因仍有限 |

本服務的差異化在於「購買データとの直接連携」——三菱食品的 ID-POS 數據讓 OOH 廣告首次能像數位廣告一樣談「コンバージョン」。未來若擴展到更多流通データ與媒體類型，有潛力成為 OOH 廣告市場的效果測定標準。
