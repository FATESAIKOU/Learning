# 4. U.S. aircraft attack Iran in response to drone strike on cargo ship that Tehran called 'ceasefire management' as both sides wrestle for Hormuz control

**Source**: https://fortune.com/2026/06/26/us-aircraft-attack-iran-drone-ship-ceasefire-strait-of-hormuz/
**Author**: Collin Binkley, Jon Gambrell, The Associated Press
**Date**: 2026-06-26
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

美軍對伊朗發動空襲，回應伊朗無人機攻擊貨輪 Ever Lovely。打擊目標為飛彈/無人機儲存點與海岸雷達站，行動約一小時內結束。此舉試圖在「維持停火」與「威懾伊朗控制荷莫茲海峽」之間走鋼索——伊朗稱攻擊是「停火管理」而非違反，美國則視之為明確的違反行為。

## 2. 這個問題為什麼會發生?(背景)

| 面向 | 細節 |
|------|------|
| 停火 MoU | 6/17 簽署，60 天談判期，要求伊朗「盡最大努力」允許商船免費通行 |
| 伊朗立場 | 「荷莫茲海峽由伊朗治理，尊重規則，勿將控制誤解為升級」——國會國安委員會主席 Azizi |
| 美國立場 | 不接受每艘船都需 IRGC 協調的「新常態」 |
| 替代航道 | IMO 推動靠阿曼沿岸的替代路線，已撤離 115 艘船，約 500 艘仍在區域內 |
| 攻擊前數據 | 6/25 攻擊前，78 艘船通過海峽（開戰以來最高，但仍低於戰前日均 130+） |
| 攻擊後 | IMO 暫停撤離；至少 2 艘油輪掉頭；仍有 20+ 艘使用南路線 |

伊朗將攻擊定性為「 ceasefire management 」，主張船隻未經伊朗許可通行即違反規則。此語義之爭反映雙方對海峽控制權的根本分歧。

## 3. 這個技術/政策是如何解決該問題的?

1. **有限打擊**：僅攻擊軍事設施，未擴大至核設施或領導層目標，訊號為「威懾非升級」
2. **時間控制**：行動在 CENTCOM 公告後約一小時結束，顯示預先規劃的精準打擊
3. **外交並行**：同日以色列-黎巴嫩宣布框架協議，為區域降溫提供潛在路徑
4. **航運數據監控**：Windward 等海運數據公司即時追蹤海峽通行量，提供客觀的緊張程度指標

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 說明 | 現狀 |
|------|------|------|
| 聯合國護航 | IMO 主導的替代航道撤離 | 已暫停，需安全保障 |
| 雙軌航道 | 伊朗控制中央航道 + 國際社會使用阿曼沿岸 | 正在測試，但伊朗視沿岸航道為挑釁 |
| 經濟槓桿 | 以制裁鬆綁/鈾濃縮談判換取航道保證 | MoU 60 天談判期內進行中 |
| 區域全面停火 | 以色列-黎巴嫩-伊朗三方協議 | 6/26 以黎框架協議為正面訊號 |
| 海上保險分攤 | 戰爭險 + 國際護航費分攤機制 | 短期可行但增加貿易成本 |

航運分析師指出：「一週的商業信心擴張遭遇首次重大考驗。」海峽雖仍運作（攻擊後 43 次通行），但「正常化速度已放緩」。關鍵變數是以黎框架協議能否為伊朗提供下台階，使荷莫茲談判回到 MoU 軌道。
