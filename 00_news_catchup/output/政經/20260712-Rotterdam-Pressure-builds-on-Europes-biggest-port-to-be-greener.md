# 08. Rotterdam: Pressure builds on Europe's biggest port to be greener

**Source**: https://www.bbc.co.uk/news/articles/c39y78rwrmno
**Author**: Anna Holligan
**Date**: July 10, 2026
**Category**: 政治經濟

## 1. 這個技術/政策解決什麼問題?

鹿特丹港是歐洲最大港口，擁有5座煉油廠（含殼牌歐洲最大煉油廠），其化石燃料流動關聯約600百萬噸CO2/年——遠超荷蘭最大機場史基浦的排放量。環保組織「Advocates for the Future」提起訴訟，要求港務局制定具體的化石燃料淘汰計劃，而非僅承諾2050年氣候中和。

核心矛盾：一個建立在化石燃料上的港口，能否真正轉型為綠色港口？

## 2. 這個問題為什麼會發生?(背景)

| 因素 | 說明 |
|------|------|
| 排放規模 | 港口工業集群年排放約29百萬噸CO2，約佔荷蘭國內排放的一半 |
| 公有企業責任 | 鹿特丹港務局是國有企業，環保組織認為應承擔更高的減排義務 |
| 全球競爭壓力 | 若規則太嚴，殼牌（已遷總部至英國）和聯合利華（已離開鹿特丹）等企業可能外移 |
| 川普政策對比 | 美國提供化石燃料優惠，削弱歐洲減排的全球競爭力 |

## 3. 這個技術/政策是如何解決該問題的?

港務局的減排計劃：

| 措施 | 說明 |
|------|------|
| 氫能樞紐 | 企業可測試新燃料 |
| 岸電設施 | 船舶靠港時接入電網而非燃燒燃料 |
| 替代燃料加注 | LNG、生質燃料、甲醇 |
| CCS（碳捕集與封存） | Porthos計畫：將工業排放CO2管線輸送至枯竭氣田儲存 |
| 自身減排目標 | 2019-2030年間削減自身直接和採購能源排放90% |

環保組織的回應：要求的是「具體的淘汰時間表」，而非長期承諾。港務局創新總監 Oscar van Veen 坦言：「我們試著與污染者合作，慢慢淘汰他們」——隨後修正為「當然是越快越好」，暴露了內部矛盾。

## 4. 是否存在解決類似問題的其他技術 / 框架 / 思考方式?

| 方案 | 案例 | 適用性 |
|------|------|--------|
| EU ETS（碳排放交易） | 已適用於歐洲港口 | 提供經濟誘因但不足以驅動根本轉型 |
| 全球統一規則 | 船舶硫排放限制（IMO 2020） | 中國最初抵制，但最終因無法進入歐美港口而跟進 |
| 綠色氫能替代 | 鹿特丹-氫能樞紐計畫 | 技術可行但成本高，需大量再生能源 |
| 港口電氣化 | 岸電 + 電動起重機 | 已在進行，但電網容量不足 |

對用戶（關注能源轉型、GCP/GKE技術）的啟示：港口減排涉及大量IoT、數據分析和自動化技術需求。鹿特丹的氫能樞紐和CCS計畫是能源科技的重要應用場景。
