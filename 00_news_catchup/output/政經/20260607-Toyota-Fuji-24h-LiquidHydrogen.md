# 34. トヨタが富士24時間で世界初の挑戦、超電導モーター搭載ポンプの入った液体水素燃料タンクを24時間レース中に交換 (原文)

## 1. 這個技術挑戰解決什麼問題?

Toyota 於 2026/06/07 富士 24 小時賽事中,執行世界首次「**24h レース中での液体水素燃料タンク交換**」,將搭載「超電導モーター駆動の液体水素ポンプ」的燃料總成(300L 真空二重槽)整組換下,耗時 3-3.5 小時。為 Toyota 氫能戰略的實證試驗。

| 規格 | 內容 |
|---|---|
| 賽事 | 富士 24 時間レース 2026 |
| 車輛 | 液体水素 GR カローラ (Rookie Racing) |
| 觸發 | インバータ錯誤警告 (1:00am) → 提早進入預定換裝程序 |
| 換裝 | 燃料 + 幫浦整組 (300L 真空二重槽) |
| 時間 | 3-3.5 小時 |
| 駕駛 | 福住仁嶺選手 (ピットアウト) |
| 技術監督 | 豊田章男 (Rookie Racing オーナー/ドライバー) |

## 2. 為什麼會發生?(背景)

### 2.1 Toyota 氫能戰略

| 時間 | 事件 |
|---|---|
| 2014 | Mirai 首款量產氫燃料電池車 |
| 2017-2020 | Mirai 二代開發,氫能推廣 (但 BEV 競爭加劇) |
| 2021-2023 | Toyota 章男「電動車狂熱」批判,主張多元路徑 |
| 2024 | Toyota 氫引擎賽車投入耐久賽 (GAZOO) |
| 2025 | 液体水素 GR カローラ + 京大 超電導モーター (永守・中村) |
| 2026/06 | 富士 24h 賽事 24h 連續行駛 + 中途換裝 |

### 2.2 為何選「液態氫」?

| 儲氫形式 | 體積能量密度 | 技術難度 |
|---|---|---|
| 高壓氣態 (700 atm) | 1.0x (基準) | 容易 (Mirai 採用) |
| 液態氫 (-253°C) | ~4x | **極高** (絕熱 + 泵浦) |
| 氫化鎂 (化學儲氫) | ~2x | 中 (研究階段) |
| 液態氨 | 較高 | 中 (腐蝕性) |

> 液態氫的優勢:同體積儲氫量為氣態的 4 倍 = 航續距離接近汽油車,這是 Toyota 對抗 BEV 的核心論點。

### 2.3 超電導モーター的技術原理

```text
傳統氫氣幫浦:
  馬達 → 油脂潤滑 → 幫浦 → 送氫
  限制: 馬達需散熱,油脂在高溫氫環境劣化

超電導馬達幫浦:
  超電導狀態 (-253°C) → 零電阻
  + 馬達與幫浦整合 → 體積小
  + 無油脂 → 直接齒輪傳動
  問題: 齒輪磨損 (無潤滑)
  解法: 正/逆反轉切換,平均化磨損
```

## 3. 24h 賽事中換裝機制如何運作?

### 3.1 換裝流程

```text
[0:00] ピットイン (福住選手下車)
  ↓
[安全作業]
  - 預先排出車側液態氫
  - 確保「超電導状態」盡量維持
  ↓
[預備作業]
  - 預先充填「替換槽」液態氫 (保持低溫)
  ↓
[分離]
  - 主燃料 2 條 (in/out) 連接器分離
  - 補機類連接器分離
  ↓
[替換作業]
  - 替換槽排出液態氫 (切換)
  - 實體燃料槽交換
  ↓
[再組裝]
  - 連接器再接續
  - 水素洩漏檢查
  - 液態氫再充填
  ↓
[5:00am 前後] リスタート
```

### 3.2 為何需要「超電導」?

| 條件 | 機制 |
|---|---|
| -253°C 環境 | 液態氫溫度,超電導自然維持 |
| 無油脂 | 油脂會固化/污染氫,故齒輪無潤滑 |
| 磨損 | 24h 連續運轉造成齒輪側磨 |
| 壽命 | 推測:超電導馬達本身 OK,但幫浦整體 24h 內達極限 |
| 解方 | 中途整組更換 (含馬達) |

### 3.3 與 BEV 的策略對比

| 軸 | BEV | Toyota 液態氫 |
|---|---|---|
| 充電時間 | 30 分鐘 (快充) | 5-10 分鐘 (氫充填) |
| 航續 | 400-600km | 推測:接近 500-700km |
| 重量 | 電池重 (500kg+) | 儲氫槽輕 (推測 100kg+) |
| 基礎建設 | 充電樁擴張中 | 加氫站稀缺 |
| 量產性 | 高 (Tesla 為主) | 低 (Mirai 累計 < 3 萬) |
| 戰略 | 中國/美國/歐盟主流 | Toyota 主導 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **Toyota 液態氫 + 超電導 (本案)** | 液態氫 + 賽道驗證 | 富士 24h 2026 | 基礎建設不足 |
| **BEV 主流路線** | 鋰電 + 快充 | Tesla, BYD | 充電時間,礦產依賴 |
| **高壓氫氣 (350/700 atm)** | Mirai 採用 | Toyota Mirai | 航續短 (< 600km) |
| **PHEV** | 引擎 + 電池 | BYD DM-i | 過渡技術 |
| **氫內燃引擎** | 直接燃燒氫 | BMW iX5 Hydrogen, Toyota Yaris H2 | 效率低於 FCV |
| **e-fuel (合成燃料)** | CO2 + 氫合成 | Porsche, Audi | 成本高 |
| **氫化鎂固態儲氫** | 常溫常壓儲氫 | 豐田/北海道大學 | 研發階段 |
| **液態氨儲氫** | 氨為氫載體 | 推測:日本/澳洲 | 毒性 |
| **換電模式 (NIO)** | 電池交換 | NIO | 需標準化 |

### 對使用者的意涵 (氫能 + Toyota 戰略)

- **Toyota 氫能戰略** 是對「BEV 唯一論」的反擊,以賽道驗證 + 技術展示推進
- 對 Softbank/管理者:理解 Toyota 多元路徑策略的長期佈局
- 對日本/台灣:氫能是「日本國家戰略」,可能成為台灣能源選項之一
- 推測:Toyota 若成功規模化液態氫,將改變全球車業能源格局
