# 33. 日産『プリメーラ』復活！フィリピン国際モーターショーで新型ピックアップとセダンの電動2モデルを公開 (原文)

**Author**: AUTOCAR JAPAN
**Date**: 2026/06/07
**Category**: 政治經濟

## 1. 這個策略解決什麼問題?

Nissan 於 2026/06/04 在「Philippine International Motor Show (PIMS) 第 10 回」發表兩款中國製電動車:**Primera EV (BEV 轎車) + Navarra Pro Plug-in Hybrid (PHEV 皮卡)**,同步展出 Kicks e-POWER 與 X-Trail e-POWER。標誌 Nissan 正式轉向「中國研發 + 全球出口」模式,Primera 車系約 20 年後復活。

| 車型 | 動力 | 定位 |
|---|---|---|
| Primera EV | BEV | 轎車 (Primera 復活) |
| Navarra Pro Plug-in Hybrid | PHEV | 皮卡 |
| Kicks e-POWER (新) | 串聯式混合 | 小型 SUV |
| X-Trail e-PHEV (新) | 插電式混合 | 中型 SUV |

## 2. 為什麼會發生?(背景)

### 2.1 Nissan 的全球戰略收縮

| 退出/縮減 | 時間 |
|---|---|
| 退出歐洲多數市場 | 2020s |
| 退出中國合資品牌定位 | 2023 (東風日產仍存在) |
| 與 Honda 合併談判破裂 | 2025/02 |
| 中國生產 + 出口 | 2026 開始 (本案) |
| 高層動態 | 內田誠 CEO 持續推動變革 |

### 2.3 為何選「東南亞」首發?

| 因素 | 機制 |
|---|---|
| 市場成長性 | 東南亞車市仍成長,中國品牌 (BYD, Chery) 積極布局 |
| 法規友善度 | 對 BEV/PHEV 補貼開放,無歐洲嚴格法規 |
| 政治風險低 | 美中對抗下,東南亞為「中立」市場 |
| 中國製接受度 | 菲律賓等市場對「中國製」接受度高 |
| 區域整合 | ASEAN 內部關稅優惠 |

## 3. Nissan 新戰略如何運作?

### 3.1 「中國創新 + 全球出口」模式

```text
[中國 (東風日產/獨立品牌)]
  研發: BEV/PHEV 平台
  生產: 中國工廠
  供應鏈: 中國在地化

[東南亞 (首發)]
  菲律賓 PIMS 2026: Primera EV + Navarra Pro PHEV
  → 泰國、印尼、馬來西亞: 後續跟進

[其他出口市場]
  推測:中東、非洲、南美
  → 歐美市場: 法規/貿易壁壘,需調整
```

### 3.2 戰略意涵

| 意涵 | 細節 |
|---|---|
| 從「全球在地化」轉向「中國中心化」 | 改用中國成本結構 + 中國研發速度 |
| e-POWER 技術海外推廣 | 串聯式混合動力為 Nissan 主力技術 IP |
| 與 Honda 合併破裂後 | 強化自家戰略,降低對外依賴 |
| 品牌重塑 | 從「日本品牌」走向「全球品牌」 |

### 3.3 為何不選歐美?

| 市場 | 障礙 |
|---|---|
| 美國 | IRA 限制 (中國製排除補助), 關稅 |
| 歐洲 | CBAM, 反傾銷稅, Euro NCAP |
| 日本 | 國產保護 (Toyota/Honda 強勢) |
| 東南亞 | 法規寬鬆,需求成長,中國接受度高 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **「中國中心化」模式 (本案)** | 中國研發 + 全球出口 | Nissan 2026 戰略 | 美歐市場受限 |
| **「多極化」模式** | 各區域獨立研發 | Toyota 區域分工 | 規模經濟差 |
| **「Indo-Pacific」模式** | 印度/ASEAN 研發中心 | Suzuki (Maruti), Hyundai | 中國威脅小 |
| **「在地收購」模式** | 收購當地品牌,加速市場進入 | Tata 收購 Jaguar Land Rover | 文化整合難 |
| **「聯盟」模式** | Renault-Nissan-Mitsubishi 聯盟 | 雷諾日產三鑽石 | 整合鬆散 |
| **「ODM 委託」模式** | 中國業者代工設計 | Apple + 富士康 | 自主品牌弱 |
| **「小而美」模式** | 專注 niche 市場 | Mazda (Wankel + 設計) | 規模有限 |
| **「氫能先行」模式** | Toyota 氫能戰略 (Bimota 案類似) | Toyota Mirai, BMW iX5 | 基礎建設不足 |

### 對使用者的意涵 (全球車業 + 戰略轉型)

- **「中國中心化」是日本車業的全新模式**,反映日企在中國的劣勢轉為優勢
- 對 Softbank/管理者:理解「全球戰略重組」的取捨,從「日本中心」走向「中國/全球」是必然
- 對台灣:Nissan 將在泰國/菲律賓生產,可評估是否引進台灣
- 對日本:Primera 復活具象徵意義,但實質影響在於中國製 BEV 進入全球市場

---

**對日本/台灣 IT 業的具體啟示**:
- 「中國研發 + 全球出口」是製造業新模式,IT 業可借鏡
- Nissan 戰略反映「次優市場」哲學:當主市場 (歐美日) 進不去時,東南亞是過渡
- 對管理者:理解「全球化」不是單一選項,可以是「中心轉移」式全球化
- 推測:Nissan 後續可能將 Primera EV 推向歐洲 (改名/調整),以避開中國品牌直接競爭
