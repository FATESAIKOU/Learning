# 17. Top 15 US States With the Highest Income (原文)

**Source**: https://www.businessinsider.com/us-states-with-highest-income-richest-2026-6
**Author**: Jordan Pandy
**Date**: 2026/06/06
**Category**: 政治經濟

## 1. 這份報告解決什麼問題?

WalletHub 依據「Top 5% 平均收入 / Bottom 20% 平均收入 / 州全體中位數家庭收入」三指標,排出 2026 年全美所得最高 15 州。意外的是:**紐約、加州、佛州(億萬富翁集中地)未進前 1**,反映「財富集中 vs 中產階級實質收入」之落差。

| 指標 | 衡量內容 | 為何重要 |
|---|---|---|
| Top 5% 平均收入 | 富裕階層實力 | 反映「極端成功者」密度 |
| Bottom 20% 平均收入 | 底層經濟活力 | 反映「共富程度」 |
| 中位數家庭收入 | 中產階級實力 | 反映「典型家庭」生活水準 |

## 2. 為何「億萬富翁州」未居冠?(背景)

### 2.1 三大主導因素

| 因素 | 機制 |
|---|---|
| 收入不均 | 紐約:Top 5% 極富,但中位數僅 $96,000 (略高於平均) |
| 富人遷出 | 加州:推測因高稅率與生活成本,高淨值人士移往德州、佛州、田納西 |
| 產業結構 | 推測:NJ、MD、VA 等州因靠近華府/醫療/生技,提供高薪中產職 |

### 2.2 排名方法學的關鍵

```text
WalletHub 綜合排名公式 (推測):
  Score = w1 * Top5% + w2 * Median + w3 * Bottom20%
  → 偏重中位數 (因 w2 通常最高)
  → 加州/紐約因不均被拉低
  → NJ/MD/VA 因「醫療/政府/科技」中產高薪,排名上升
```

### 2.3 各州產業地圖

| 州 (推測) | 主導產業 |
|---|---|
| NJ | 製藥、通訊、靠近 NYC 金融 |
| MD | 聯邦政府、生物科技 (NIH 旁) |
| VA | 國防/政府承包、IT (Amazon HQ2 旁) |
| MA | 生技、教育、醫療 |
| CT | 保險、避險基金 |
| WA | 科技 (Microsoft, Amazon) |
| CO | 科技、航空 |

## 3. 這份報告揭示的結構性問題

### 3.1 「高收入州 ≠ 低生活成本」

| 州 | 推測:生活成本指數 |
|---|---|
| 加州 | 150+ (全美最高) |
| 紐約 | 140+ |
| 紐澤西 | 120+ |
| 德州 | 95-100 |
| 田納西 | 85-90 |

→ 純看名目收入易誤導,**實質購買力 (real purchasing power)** 才是關鍵

### 3.2 「中產階級衰退」現象

- 推測:中位數家庭收入停滯,但 Top 5% 持續成長
- 反映「K 型復甦」(K-shaped recovery)
- 政治後果:民粹主義、跨黨派不滿

### 3.3 科技業地理集中

- WA/CA/CO/TX 形成科技走廊,推升當地中位數
- 推測:遠端工作使部分高薪職位分散,但整體仍集中
- 對日本/台灣的啟示:科技園區政策需考慮「薪資外溢效應」

## 4. 解決類似問題的其他思考方式 / 框架

| 框架 | 機制 | 應用 | 限制 |
|---|---|---|---|
| **WalletHub 三指標法 (本案)** | 結合極端值 + 中位數 + 底層 | 收入比較 | 公式權重不公開 |
| **Gini 係數** | 衡量收入不均 (0=完全平等) | 經濟學標準 | 不反映絕對水準 |
| **生活成本調整 (COLA)** | 名目收入 / 地區物價指數 | 跨州比較 | 物價指數不精確 |
| **購買力平價 (PPP)** | 跨國/跨區實質比較 | OECD 標準 | 美國內部少用 |
| **OECD Better Life Index** | 11 面向 (收入 + 工作 + 教育 + 健康 + 環境等) | 國家比較 | 主觀權重 |
| **推測:中位數工時對比** | 中位數收入 / 中位數工時 | 真實生活水平 | 工時數據難取得 |
| **推測:資產 vs 流量** | 區分「流動收入」與「家庭資產」 | 退休規劃 | 資產資料不完整 |

### 對使用者的意涵 (薪資設計 / 招募策略)

- **薪資 benchmark** 應以「同產業 + 同生活成本區」為基準,非單純「同城市」
- 日本 Softbank 若招募海外人才 (美/台/印度),需以「實質購買力」對齊薪資
- 管理者:理解「K 型經濟」對員工 morale 的影響,高薪資 + 高物價的雙重壓力
- 跨國派駐成本估算應使用購買力平價,非名目匯率
