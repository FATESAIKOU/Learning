# 25. 型破りな広告で知られるクリエティブエージェンシー ケッセルスクライマーが破産申請 (原文)

**Source**: https://www.advertimes.com/20260605/article546547/
**Author**: Advertimes 編集部
**Date**: 2026/06/05
**Category**: 政治經濟

## 1. 這則新聞呈現什麼問題?

荷蘭・アムステルダム傳奇獨立創意代理商 KesselsKramer(以下 KK),於 2026/06/02 宣布破產申請。KK 成立於 1996 年,以反骨創意聞名,代表作包括「Hans Brinker Budget Hotel 世界最悪のホテル」、「I am Ben」、「I amsterdam」城市 slogan 等,並拓展至倫敦、洛杉磯、出版社、畫廊。

| 維度 | 狀態 |
|---|---|
| 創立 | 1996, Kessels + Kramer |
| 總部 | Amsterdam, Laurier Canal 19 世紀教堂改裝辦公室 |
| 員工 | 推測:200-300 人 |
| 客戶 | Ben (荷蘭電信), Diesel, Nike, NRW-Forum |
| 文化 | 反骨、anti-advertising、found-photo 收藏 |
| 終局 | 2026/06 破產申請 |

## 2. 為什麼會發生?(背景)

### 2.1 獨立廣告代理商的結構性困境

| 因素 | 機制 |
|---|---|
| 利潤壓縮 | 客戶端要求 transparency,媒體購買毛利下降 |
| 集團化競爭 | WPP/Omnicom/Publicis/IPG 透過規模壓低報價 |
| In-house 化 | 大品牌 (Nike, Patagonia) 把創意收回自製 |
| 平台廣告 | Meta/Google 直接吃掉數位廣告預算 |
| 經濟循環 | 2024-2025 廣告市場雖成長,利潤卻集中於平台 |

### 2.2 KK 的「獨立性」代價

| 優勢 | 副作用 |
|---|---|
| 文化品牌強 | 難以規模化,營收天花板低 |
| 拒絕量產 | 無法服務超大客戶 |
| 創作者主導 | 經營效率低,難吸引營運人才 |
| 多元業務 (出版社、畫廊) | 分散資源,非核心業務虧損 |
| 倫敦/LA 擴張 | 跨國管理複雜,固定成本高 |

### 2.3 廣告業的 AI 衝擊

- 生成式 AI 降低「普通創意」成本
- KK 的優勢在「極端創意」,但需求仍受壓縮
- 推測:客戶改用 AI 工具 + 小型工作室,跳過傳統代理商
- 廣告代理商在「AI 生成時代」需重新定義價值

## 3. KK 的經營模式如何運作?為何失效?

### 3.1 KK 模式解析

```text
定位: 獨立創意 boutique
客戶: 願意為「故事」付費的品牌 (Ben, Diesel, Nike, 城市觀光)
人才: 創意型 (writer, art director, 攝影師)
流程: 強烈文化導向、anti-corporate
獲利: 概念費 (creative fee) + 媒體佣金 (放棄 transparency 後萎縮)
```

### 3.2 經典案例

| 案例 | 年份 | 手法 |
|---|---|---|
| Hans Brinker 「世界最悪のホテル」 | 1990s | 自嘲逆轉,將負評變話題 |
| 「I am Ben」 | 2000s | 荷蘭電信 1-to-1 品牌定位 |
| 「I amsterdam」 | 2004 | 城市 slogan, 紅白字母裝置藝術 |
| 「The Other Final」 | 2002 | FIFA 倒數賽(布甸 vs 蒙塞拉特) |
| 廢棄家庭相簿收藏 | 持續 | Kessels 個人 side project |

### 3.3 為何仍破產?

| 失敗訊號 | 推測原因 |
|---|---|
| 客戶流失 | Diesel/Nike 等大客戶轉向集團代理商或 in-house |
| 媒體業務萎縮 | 數位廣告被平台吸收 |
| 多元業務拖累 | 出版社、畫廊非核心,虧損擴大 |
| 後繼人才 | 創辦人年齡 + 新世代流失 |
| 宏觀因素 | 2024-2025 廣告市場雖成長,獨立 boutique 受擠壓最嚴重 |

## 4. 解決類似問題的其他模式 / 思考方式

| 模式 | 機制 | 案例 | 限制 |
|---|---|---|---|
| **KK 模式 (本案)** | 獨立、創意為王 | KesselsKramer | 規模天花板低 |
| **W+K 模式** | 集團資源 + 創意自主 | Wieden+Kennedy | 母公司資金壓力大 |
| **Holding company 模式** | WPP/Omnicom 規模化 | Ogilvy, BBDO | 創意同質化 |
| **In-house 模式** | 品牌內部團隊 | Nike, Patagonia, Google Creative | 創意新血少 |
| **AI-augmented 創意工作室** | AI 工具 + 頂級創意 | 推測:Toolkit, Pencil | 仍需人類把關 |
| **Platform agency** | Meta/Google Creative Shop | 平台 in-house | 利益衝突 |
| **工作室網絡 (Collective)** | 多個小工作室共享資源 | Mother, Droga, 72andSunny | 治理複雜 |
| **NGO/文化導向** | 公共案 + 商業案混合 | Pentagram | 商業規模有限 |
| **AI-native agency** | 從 day 1 採 AI 工作流 | 推測:Pencil, AdCreative.ai | 創意品味被質疑 |

### 對使用者的意涵 (廣告業 + 創意經濟)

- **獨立代理商的黃金時代可能結束**,被集團 + in-house + AI 三方擠壓
- 對 Softbank/管理者:招募行銷/品牌人才時,「獨立代理商歷練」仍具稀缺價值
- 對日本/台灣:本地獨立代理商 (電通以外) 面臨類似壓力
- 推測:AI 工具 + 創意 boutique = 未來主流,但「極端創意」的需求仍在

---

**對日本/台灣廣告業的啟示**:
- KK 破產對台灣奧美/電通/意識形態等代理商是警訊
- 「文化品牌」+「商業經營」難以兼顧,需有規模化策略
- 對廣告人:「極端創意」仍是人類最難被 AI 取代的領域,值得捍衛
- 對管理者:理解代理商的價值定位,在集團/獨立/AI 工具間靈活組合
