# Information Disclosure via Unauthenticated /courses Endpoint

**ID:** vuln-0003
**Severity:** MEDIUM
**Found:** 2026-07-14 08:04:29 UTC
**Target:** https://api.axross-recipe.com
**Endpoint:** /courses
**Method:** GET
**CWE:** CWE-200
**CVSS:** 5.3

## Description

The /courses endpoint at api.axross-recipe.com returns all course data (approximately 98KB) without any authentication. This exposes course titles, descriptions, and potentially sensitive educational content to unauthenticated users.

## Impact

An attacker can enumerate all courses available on the platform, including their descriptions and metadata. While courses may be intended to be publicly visible, the lack of authentication on this bulk data endpoint could expose course structures, pricing information, and other metadata that could be used for competitive analysis or targeted attacks.

## Technical Analysis

The /courses endpoint is a Rails API endpoint that returns all course records without any authentication check. The endpoint returns a large JSON array (98KB) containing course objects with titles, descriptions, and other metadata. The endpoint is accessible via a simple GET request with no authentication headers required.

## Proof of Concept

1. Send a GET request to https://api.axross-recipe.com/courses
2. Observe the response contains all course data (98KB)
3. No authentication headers or session cookies are required

```
curl -s https://api.axross-recipe.com/courses | python3 -c "import sys,json; data=json.load(sys.stdin); print(f'Total courses: {len(data)}'); [print(f'  - {c[\"id\"]}: {c[\"title\"]}') for c in data[:10]]"
```

## Remediation

1. Add authentication checks to the /courses endpoint if the data should be protected
2. If courses are meant to be public, consider implementing pagination and rate limiting
3. Review what course metadata is exposed and whether any fields contain sensitive information
