# Weak Password Policy - No Minimum Password Requirements

**ID:** vuln-0005
**Severity:** MEDIUM
**Found:** 2026-07-14 08:35:15 UTC
**Target:** https://api.axross-recipe.com/signup
**Endpoint:** /signup
**Method:** POST
**CWE:** CWE-521
**CVSS:** 6.5

## Description

The registration endpoint does not enforce any password complexity requirements. Single-character passwords are accepted, and there is no minimum length, character variety, or strength validation. This allows users to create accounts with trivially guessable passwords.

## Impact

User accounts can be created with extremely weak passwords (e.g., "a"), making them vulnerable to brute-force attacks and password spraying. An attacker could compromise accounts by attempting common weak passwords across multiple user accounts. This undermines the security of the entire platform.

## Technical Analysis

The Rails backend does not include any password validation logic in the registration flow. The User model appears to lack password complexity validations. While Devise or similar authentication gems typically provide password length configuration, the application has either disabled these validations or is using a custom authentication implementation that does not enforce password policies.

## Proof of Concept

1. Send a registration request with a single-character password
2. The server accepts the registration and creates the account
3. The account can now be accessed with the weak password "a"

curl -X POST https://api.axross-recipe.com/signup \
  -H "Content-Type: application/json" \
  -d '{"username":"weakuser","email":"weak@test.com","password":"a","password_confirmation":"a","agreed_to_terms":true}'
Response: {"result":"success"}

```
#!/usr/bin/env python3
"""Weak Password Policy PoC"""
import requests

TARGET = "https://api.axross-recipe.com/signup"

weak_passwords = ["a", "123", "password", "pass", "test", "abc123"]

for pw in weak_passwords:
    payload = {
        "username": f"weakpwtest_{pw}",
        "email": f"weakpwtest_{pw}@test.com",
        "password": pw,
        "password_confirmation": pw,
        "agreed_to_terms": True
    }
    resp = requests.post(TARGET, json=payload, 
        headers={"Content-Type": "application/json", "Origin": "https://axross-recipe.com"})
    result = "ACCEPTED" if "success" in resp.text else "REJECTED"
    print(f"Password '{pw}': {result}")
```

## Remediation

1. Implement a minimum password length of at least 8 characters.
2. Require a mix of character types: uppercase, lowercase, numbers, and special characters.
3. Check passwords against common password lists and reject known weak passwords.
4. Implement password strength scoring using libraries like zxcvbn.
5. Consider implementing multi-factor authentication for additional account security.
